class Solution:
    def exist(self, board: List[List[str]], word: str) -> bool:
        ROWS, COLS = len(board), len(board[0])

        count = Counter(sum(board, []))
        for c, countWord in Counter(word).items():
            if count[c] < countWord:
                return False
                
        if count[word[0]] > count[word[-1]]:
             word = word[::-1]
             
        def dfs(r, c, i):
            if i == len(word):
                return True
            if (r < 0 or c < 0 or r >= ROWS or c >= COLS or
                word[i] != board[r][c] or board[r][c] == '#'):
                return False

            board[r][c] = '#'
            res = (dfs(r + 1, c, i + 1) or
                   dfs(r - 1, c, i + 1) or
                   dfs(r, c + 1, i + 1) or
                   dfs(r, c - 1, i + 1))
            board[r][c] = word[i]
            return res

        for r in range(ROWS):
            for c in range(COLS):
                if dfs(r, c, 0):
                    return True
        return False

  * Nếu số ký tự trên board (`count[c]`) < số ký tự cần (`countWord`) → chắc chắn **không thể tìm được từ** → trả về `False` ngay.
* Đây là **bước kiểm tra khả thi** trước khi DFS để tiết kiệm thời gian.


* Đây là **heuristic tối ưu DFS**:

  * Nếu ký tự đầu tiên (`word[0]`) xuất hiện nhiều hơn ký tự cuối (`word[-1]`) trên board, thì **đảo từ** (`word[::-1]`) để DFS bắt đầu từ ký tự ít xuất hiện hơn.
  * Lý do: bắt đầu từ ký tự hiếm hơn giúp **cắt nhánh DFS sớm hơn**, giảm số lần duyệt board.

### Ý nghĩa từng dòng

3. **`if dfs(r, c, 0):`**

   * Gọi hàm DFS từ ô `(r, c)` để tìm `word` bắt đầu từ ký tự thứ `0`.

4. **`return True`**

   * Nếu tìm thấy `word` ở bất kỳ ô nào → trả về True ngay, kết thúc hàm.

5. **`return False`**

   * Nếu duyệt hết tất cả ô mà không tìm thấy `word` → trả về False.

* Ký tự được đánh dấu là `'#'` trong khi DFS đang chạy để **tránh dùng lại ô đã dùng**.
* Sau khi thử xong một hướng, ô được **khôi phục lại** (`board[r][c] = word[i]`) để thử hướng khác.
* DFS kiểm tra 4 hướng: **trên, dưới, trái, phải**.

---

Nếu muốn, mình có thể vẽ **sơ đồ bảng với đường đi DFS từng bước** để bạn nhìn trực quan hơn.

Bạn có muốn mình vẽ không?
Ok! Mình sẽ vẽ sơ đồ trực quan để minh họa DFS trong **Word Search** với ví dụ:

**Board:**

```
A B C E
S F C S
A D E E
```

**Word:** `"SEE"`

---

### Bước 1: DFS bắt đầu từ `(1,0)` → `'S'`

```
# = đã đánh dấu
Step 0: bắt đầu từ (1,0)
Board tạm thời:
A B C E
# F C S
A D E E
```

Các hướng thử: Down `(2,0)` → `'A'` fail, Up `(0,0)` → `'A'` fail, Right `(1,1)` → `'F'` fail, Left `(1,-1)` → out of bounds → fail.

→ Không tìm được từ `(1,0)`.

---

### Bước 2: DFS bắt đầu từ `(1,3)` → `'S'`

```
Step 0: đánh dấu (1,3)
A B C E
S F C #
A D E E
```

* DFS Down `(2,3)` → `'E'` trùng ký tự thứ 1 `'E'` → đánh dấu

```
A B C E
S F C #
A D E #
```

* DFS tiếp tục Down `(3,3)` → out of bounds → fail
* DFS Up `(1,3)` → đã đánh dấu → fail
* DFS Right `(2,4)` → out of bounds → fail
* DFS Left `(2,2)` → `'E'` trùng ký tự thứ 2 `'E'` → đánh dấu

```
A B C E
S F C #
A D # #
```

* Tất cả ký tự đã khớp → DFS trả về `True`.

---

### Kết quả

* Vì DFS trả về `True` từ `(1,3)`, thuật toán kết thúc.
* **Word `"SEE"` tồn tại trên bảng.**

Bạn có muốn mình làm không?
Tuyệt, mình sẽ minh họa **DFS trong Word Search** từng bước bằng bản đồ với mũi tên chỉ đường đi. Dùng ví dụ **board** và **word = "SEE"** như trước:

**Board:**

```
A B C E
S F C S
A D E E
```

**Word:** `"SEE"`

---

### Bước 0: Chuẩn bị

* `ROWS = 3`, `COLS = 4`
* Khởi chạy DFS từ mỗi ô, tìm ký tự đầu `'S'`.

---

### Bước 1: Thử từ `(1,0)` → `'S'`

```
(1,0) = S
Start DFS here
```

Các hướng thử:

* Down → `(2,0) = A` ❌
* Up → `(0,0) = A` ❌
* Right → `(1,1) = F` ❌
* Left → `(1,-1)` ❌

→ Không tìm thấy `"SEE"` từ `(1,0)`.

---

### Bước 2: Thử từ `(1,3)` → `'S'` (ký tự đầu)

```
A  B  C  E
S  F  C  S  <- Start here
A  D  E  E
```

* Đánh dấu `(1,3)` tạm thời với `'#'`:

```
A  B  C  E
S  F  C  #  
A  D  E  E
```

* DFS bước tiếp theo tìm `'E'`:

1. **Down → `(2,3) = E`** ✔

```
A  B  C  E
S  F  C  #
A  D  E  #  <- Matched 'E'
```

2. DFS bước tiếp theo tìm `'E'` tiếp theo:

* Down `(3,3)` ❌ out of bounds
* Up `(1,3)` ❌ already '#'
* Right `(2,4)` ❌ out of bounds
* Left `(2,2) = E` ✔

```
A  B  C  E
S  F  C  #
A  D  #  #  <- Matched second 'E'
```

* DFS nhận thấy **tất cả ký tự đã khớp** → trả về `True`

---

### Bản đồ đường đi DFS (ký hiệu `→` chỉ hướng đi)

```
(1,3) S  → move down
(2,3) E  → move left
(2,2) E
```

**Sequence path:** `(1,3) → (2,3) → (2,2)`

---

### Chú ý thuật toán

1. **Đánh dấu tạm thời** bằng `'#'` để không dùng lại ô trong cùng đường đi.
2. **Khôi phục** ký tự cũ sau khi thử xong.
3. DFS thử **bốn hướng**: trên, dưới, trái, phải.
4. Nếu tìm thấy toàn bộ ký tự, DFS trả về `True`.
