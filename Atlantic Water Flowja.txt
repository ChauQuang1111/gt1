class Solution {

    List<List<Integer>> pacificAtlantic(int[][] matrix) {
        return new java.util.AbstractList<List<Integer>>() {
            private List<List<Integer>> res;

            public List<Integer> get(int i) {
                init();
                return res.get(i);
            }

            public int size() {
                init();
                return res.size();
            }

            private void init() {
                if (res==null) {
                    res=solve(matrix);
                }
            }
        };
    }
    private static final int[][] directions = new int[][]{{0, 1}, {0, -1}, {1, 0}, {-1, 0}};
    
    public List<List<Integer>> solve(int[][] matrix) {
        
        List<List<Integer>> res=new ArrayList<>();
        if (matrix==null || matrix.length==0) {
            return res;
        }
        int m=matrix.length;
        int n=matrix[0].length;
        char[][] visited=new char[m][n];
        for (int col=0; col<n; col++) {
            dfs(matrix, 0, col, visited, 'P', res);
        }
        for (int row=0; row<m; row++) {
            dfs(matrix, row, 0, visited, 'P', res);
        }      
        for (int col=0; col<n; col++) {
            dfs(matrix, m-1, col, visited, 'A', res);
        }
        for (int row=0; row<m; row++) {
            dfs(matrix, row, n-1, visited, 'A', res);
        }
        return res;
    }
    
    private void dfs(int[][] matrix, int row, int col, char[][] visited, char ch, List<List<Integer>> res) {
        if (visited[row][col]=='P' && ch=='A') {
            res.add(new ArrayList<Integer>() {{
                add(row);
                add(col);
            }});
        }
        visited[row][col]=ch;
        for (int[] dir : directions) {
            int x=row+dir[0];
            int y=col+dir[1];
            if (x>=0 && x<matrix.length && y>=0 && y<matrix[0].length && matrix[row][col]<=matrix[x][y] && visited[x][y]!=ch) {
                dfs(matrix, x, y, visited, ch, res);
            }
        }        
    }
}

## 🧠 Ý tưởng bài toán

* Ta có một **bản đồ độ cao** (`matrix[i][j]`).
* Nước **chảy từ ô có độ cao cao hơn sang ô có độ cao thấp hơn hoặc bằng**.
* **Thái Bình Dương (Pacific)** nằm ở **biên trên và biên trái**.
* **Đại Tây Dương (Atlantic)** nằm ở **biên dưới và biên phải**.
* Yêu cầu: tìm **tất cả ô** mà **nước từ ô đó có thể chảy đến cả 2 đại dương**.

---

## 🚀 Ý tưởng thuật toán

Thay vì **duyệt từ mỗi ô để xem có chảy được ra biển không** (rất tốn thời gian, O(m×n×m×n)),
ta làm **ngược lại**:

👉 Ta **duyệt từ hai đại dương vào trong**, mô phỏng **nước “chảy ngược dòng”**, nghĩa là từ biển đi ngược lên các ô cao hơn hoặc bằng.

Như vậy:

* Nếu từ biển Thái Bình Dương ta có thể đi đến ô `(i,j)` → nước từ `(i,j)` có thể chảy ra Thái Bình Dương.
* Nếu từ biển Đại Tây Dương ta cũng có thể đi đến `(i,j)` → nước từ `(i,j)` có thể chảy đến Đại Tây Dương.

=> Giao của 2 tập hợp đó là kết quả cuối cùng ✅

## 🧱 Giải thích từng dòng code:

```java
private void dfs(int[][] matrix, int row, int col, char[][] visited, char ch, List<List<Integer>> res) {
```

* `matrix`: bản đồ độ cao.
* `row`, `col`: vị trí hiện tại.
* `visited`: mảng đánh dấu trạng thái mỗi ô:

  * `'A'` → có thể chảy đến Atlantic


* `x >= 0 && x < matrix.length && y >= 0 && y < matrix[0].length`:

* `matrix[row][col] <= matrix[x][y]`:

* `visited[x][y] != ch`:

1. Khi gọi `dfs()` từ **biên của Thái Bình Dương**:

   * Nó đánh dấu tất cả ô **nước có thể chảy ra Thái Bình Dương**.

2. Khi gọi `dfs()` từ **biên của Đại Tây Dương**:

   * Nó đánh dấu tất cả ô **nước có thể chảy ra Đại Tây Dương**.

3. Nếu một ô được đánh dấu bởi **cả hai DFS**,
