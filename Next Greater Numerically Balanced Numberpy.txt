Next Greater Numerically Balanced Number
class Solution:
    def generate(self, n: int, current: int, remaining: int, count: list[int]) -> int:
        if remaining == 0:
            if current > n and all(c == 0 or c == i for i, c in enumerate(count)):
                return current
            return 0

        result = 0
        for d in range(1, 10):
            if result == 0 and count[d] < d and d - count[d] <= remaining:
                count[d] += 1
                result = self.generate(n, current * 10 + d, remaining - 1, count)
                count[d] -= 1
        return result

    def nextBeautifulNumber(self, n: int) -> int:
        length = len(str(n))
        count = [0] * 10

        result = self.generate(n, 0, length, count)
        count = [0] * 10
        next_len_result = self.generate(0, 0, length + 1, count)
        if result == 0:
            result = next_len_result
        return result

Mình sẽ giải thích thật dễ hiểu từng phần cho bạn 👇

## 🧠 Trước tiên: hiểu đề bài

> Một **numerically balanced number** là số mà **chữ số i xuất hiện đúng i lần**.
> Ví dụ:
>
> * 1 → ❌ (vì số 1 xuất hiện 1 lần ✅, nhưng không có chữ số khác nào, ok)
> * 22 → ✅ (chữ số 2 xuất hiện đúng 2 lần)
> * 122333 → ✅ (1 một lần, 2 hai lần, 3 ba lần)
> * 1333 ❌ (1 một lần đúng, nhưng 3 xuất hiện 3 lần → đúng, ok)
>   → Actually ✅ vì 1 một lần, 3 ba lần.

Nhiệm vụ:
Cho `n`, tìm **số nhỏ nhất lớn hơn n** mà là numerically balanced.

---

## 🧩 Phần 1: `generate()`

```python
def generate(self, n: int, current: int, remaining: int, count: list[int]) -> int:
    if remaining == 0:
        if current > n and all(c == 0 or c == i for i, c in enumerate(count)):
            return current
        return 0
```

### Giải thích:

* `n`: số gốc bạn đang muốn vượt qua (ví dụ n = 31)
* `current`: số đang được tạo dần (bằng cách thêm từng chữ số)
* `remaining`: số chữ số còn lại cần thêm
* `count`: mảng lưu số lần xuất hiện của mỗi chữ số từ 0 đến 9

---

Khi `remaining == 0`, tức là bạn đã tạo xong một số có độ dài cố định.

Lúc này kiểm tra:

```python
if current > n and all(c == 0 or c == i for i, c in enumerate(count)):
```

📘 Nghĩa là:

* Số vừa tạo phải **lớn hơn n**
* Và mỗi chữ số i phải **xuất hiện đúng i lần** (`c == i`)
* Nếu chữ số không xuất hiện thì `c == 0` (được phép)

✅ Nếu thỏa → return `current`,
❌ Nếu không → return 0.

## 🧩 Phần 2: vòng lặp sinh chữ số

```python
result = 0
for d in range(1, 10):
    if result == 0 and count[d] < d and d - count[d] <= remaining:

        result = self.generate(n, current * 10 + d, remaining - 1, count)

return result
```

### Giải thích chi tiết:

* Duyệt từng chữ số `d` từ 1 → 9
  (0 bị bỏ qua vì không được làm chữ số đầu)

---

### Điều kiện sinh nhánh mới:

```python
count[d] < d
```

👉 Chữ số d chưa xuất hiện đủ số lần d cho phép.
Ví dụ: với `d = 2`, ta chỉ có thể thêm tối đa 2 lần chữ số 2.

---

### `d - count[d] <= remaining`

👉 Nghĩa là ta **vẫn có đủ chỗ để hoàn thành d** lần xuất hiện chữ số đó.
Nếu không đủ chỗ, ta bỏ qua vì không thể tạo số balanced được.

---

### Gọi đệ quy:

```python
count[d] += 1
result = self.generate(n, current * 10 + d, remaining - 1, count)
count[d] -= 1
```

Ta thử thêm chữ số `d` vào cuối `current`,
giảm `remaining` đi 1, rồi tiếp tục sinh.

---

### `if result == 0` là gì?

→ Khi tìm được **kết quả hợp lệ đầu tiên**, dừng luôn (vì ta muốn *số nhỏ nhất lớn hơn n*).
Không cần sinh thêm nữa.

## 🧩 Phần 3: Hàm chính

```python
def nextBeautifulNumber(self, n: int) -> int:
    length = len(str(n))
    count = [0] * 10

    result = self.generate(n, 0, length, count)
    count = [0] * 10
    next_len_result = self.generate(0, 0, length + 1, count)
    if result == 0:
        result = next_len_result
    return result
```

### Từng bước:

1️⃣ `length = len(str(n))`:
→ số chữ số của `n`.

2️⃣ Gọi `generate(n, 0, length, count)`
→ thử tìm số balanced có cùng độ dài.

3️⃣ Nếu **không có**, thì thử với **số có độ dài lớn hơn 1 chữ số** (`length + 1`).

122 ✅ (1 một lần, 2 hai lần)

## 🧠 Mục tiêu

→ Tìm **số nhỏ nhất lớn hơn n** mà **các chữ số i xuất hiện đúng i lần**
(ví dụ: `122333`, `22`, `333`, ...)

---

## 🔍 Giải thích từng dòng

### ✅ 1. `length = len(str(n))`

* Đếm **số chữ số của n**
  Ví dụ:

  ```
  n = 31 → length = 2
  n = 122 → length = 3
  ```

* Mục đích: để biết cần sinh các số có **cùng độ dài** với n trước.
  (vì số lớn hơn gần nhất **thường có cùng độ dài**)

---

### ✅ 2. `count = [0] * 10`

* Tạo mảng `count` gồm 10 phần tử (từ 0–9), ban đầu toàn 0.

* Dùng để **đếm số lần xuất hiện** của mỗi chữ số trong quá trình sinh số.

  Ví dụ: nếu đang tạo số `122`, thì

  ```
  count = [0,1,2,0,0,0,0,0,0,0]
  ```

  nghĩa là:

  * Chữ số `1` xuất hiện 1 lần ✅
  * Chữ số `2` xuất hiện 2 lần ✅

---

### ✅ 3. `result = self.generate(n, 0, length, count)`

* Gọi hàm `generate()` để **sinh ra các số có độ dài = length**
* Bắt đầu từ `current = 0` (chưa có chữ số nào)
* `remaining = length` là số chữ số cần thêm
* `count` là mảng theo dõi số lần xuất hiện

Hàm `generate()` sẽ **tạo tất cả các số balanced có đúng `length` chữ số**
và **tìm số nhỏ nhất lớn hơn n**.

---

### ✅ 4. `count = [0] * 10`

* Reset lại `count` để bắt đầu đếm mới cho trường hợp tiếp theo.

---

### ✅ 5. `next_len_result = self.generate(0, 0, length + 1, count)`

* Gọi `generate()` một lần nữa, **nhưng với số có độ dài lớn hơn 1**.
  → vì có thể **không tồn tại số balanced nào lớn hơn n mà vẫn cùng độ dài**.

Ví dụ:

* n = 99
  → Không có số balanced 2 chữ số > 99
  → Thử sang 3 chữ số → 122 ✅

---

### ✅ 6. `if result == 0: result = next_len_result`

* Nếu không tìm được số balanced nào ở độ dài cũ (`result == 0`)
  → Lấy kết quả từ độ dài dài hơn (`next_len_result`).

---

### ✅ 7. `return result`

* Trả về kết quả cuối cùng:
  **số nhỏ nhất lớn hơn n mà là numerically balanced**.
