class Solution {
    public int trapRainWater(int[][] heightMap) {
        int m = heightMap.length;
        int n = heightMap[0].length;
        int[][] vols = new int[m][n];
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                vols[i][j] = heightMap[i][j];

            }

        }
         boolean upt = true;
         boolean init = true;

          
         while (upt) {
             upt = false;
               for (int i = 1; i < m - 1; i++) { 
                for (int j = 1; j < n - 1; j++) {
                    int val = Math.max(heightMap[i][j],
                             Math.min(vols[i - 1][j], vols[i][j - 1]));
                    if (init || vols[i][j] > val) {
                        vols[i][j] = val;
                        upt = true;

                    }         

                }


               }
                init = false;
                 for (int i = m - 2; i >= 1; i--) { 
                     for (int j = n - 2; j >= 1; j--) { 
                        int val = Math.max(heightMap[i][j],
                                  Math.min(vols[i + 1][j], vols[i][j + 1]));
                         if (vols[i][j] > val) {
                              vols[i][j] = val;
                              upt = true;

                         }

                     }

                 }

         } 
          int res = 0;
          for (int i = 1; i < m - 1; i++) { 
             for (int j = 1; j < n - 1; j++) { 
                if (vols[i][j] > heightMap[i][j])
                 res += vols[i][j] - heightMap[i][j];

             }

          }
         return res;
    }
}
À đoạn này là trong **cách giải “quét đi quét lại”** của bạn lúc trước đúng không 👍.
Mình giải thích tại sao phải set `upt = true` và `init = true` ban đầu:

---

### 1. `boolean upt = true;`

* Ý nghĩa: **có cập nhật (update) hay không**.
* Ban đầu set `true` để chắc chắn vòng lặp `while (upt)` chạy **ít nhất một lần**.
* Trong mỗi vòng lặp:

  * Nếu có ô nào được cập nhật giá trị (`vols[i][j]` thay đổi), thì `upt = true` → tiếp tục chạy vòng sau.
  * Nếu không còn thay đổi nào nữa, `upt = false` → dừng vòng lặp.

📌 Đây là một **cách kiểm soát lặp đến khi ổn định** (giống iterative relaxation trong DP).

---

### 2. `boolean init = true;`

* Ý nghĩa: đánh dấu **vòng lặp đầu tiên**.
* Trong đoạn code của bạn có chỗ:

  ```java
  if (init || vols[i][j] > val) {
      vols[i][j] = val;
      upt = true;
  }
  ```

  * Ở lần đầu tiên (`init = true`) → luôn cho phép cập nhật để khởi tạo `vols`.
  * Sau vòng đầu tiên, gán `init = false`. Lúc này chỉ cập nhật khi **có sự cải thiện thật sự** (`vols[i][j] > val`).

📌 Cái này giúp đảm bảo bước đầu tiên điền giá trị cho tất cả ô, rồi những vòng sau chỉ tinh chỉnh.

---

👉 Tóm lại:

* `upt = true`: để chắc chắn vòng lặp chạy ít nhất một lần, và còn lặp cho đến khi không còn thay đổi.
* `init = true`: để vòng lặp đầu tiên cập nhật mọi ô, sau đó chỉ cập nhật khi có cải thiện.

### Vòng lặp:

```java
while (upt) {
    upt = false;
    for (int i = 1; i < m - 1; i++) { 
        for (int j = 1; j < n - 1; j++) {
            int val = Math.max(heightMap[i][j],
                     Math.min(vols[i - 1][j], vols[i][j - 1]));
            if (init || vols[i][j] > val) {
                vols[i][j] = val;
                upt = true;
            }         
        }
    }
}
```

---

### Giải thích từng phần:

1. **`while (upt)`**

   * Lặp cho đến khi **không còn thay đổi nào** (`upt = false`).
   * Ý tưởng: ta “quét” ma trận nhiều lần, tinh chỉnh dần thể tích nước có thể chứa.

---

2. **`upt = false;`**

   * Trước mỗi vòng, giả sử không có thay đổi.
   * Nếu trong quá trình quét có cập nhật, ta set lại `upt = true`.

---

3. **`for (int i = 1; i < m - 1; i++)`**

   * Duyệt **hàng** từ 1 → `m-2` (bỏ viền ngoài, vì viền không giữ nước được).

4. **`for (int j = 1; j < n - 1; j++)`**

   * Duyệt **cột** từ 1 → `n-2`, cũng bỏ viền ngoài.

---

5. **`int val = Math.max(heightMap[i][j], Math.min(vols[i - 1][j], vols[i][j - 1]));`**

   👉 Ý nghĩa: cập nhật mức nước tối thiểu mà ô `(i,j)` có thể giữ.

   * `vols[i - 1][j]` : mực nước ở ô phía **trên**.
   * `vols[i][j - 1]` : mực nước ở ô **bên trái**.
   * `Math.min(vols[i - 1][j], vols[i][j - 1])` : mức nước tối đa mà `(i,j)` có thể đạt, dựa trên hai ô này.
   * `Math.max(heightMap[i][j], … )` : ô `(i,j)` ít nhất phải cao bằng chính độ cao của nó (`heightMap[i][j]`), vì nước không thể thấp hơn nền.

   ➝ `val` = mức nước ổn định mới cho `(i,j)`.

---

6. **`if (init || vols[i][j] > val)`**

   * Nếu là vòng đầu tiên (`init == true`) → luôn cập nhật.
   * Nếu không phải vòng đầu → chỉ cập nhật khi mực nước cũ `vols[i][j]` cao hơn `val` (nghĩa là có thể giảm xuống, hợp lý hơn).

---

7. **`vols[i][j] = val;`**

   * Cập nhật mực nước mới cho ô `(i,j)`.

8. **`upt = true;`**

   * Vì có cập nhật, nên vòng ngoài phải chạy lại lần nữa để kiểm tra các ô liên quan.

---

👉 Tóm gọn:
Đoạn này giống như **lan truyền giá trị nước từ trên trái xuống dưới phải**. Mỗi ô được chỉnh lại sao cho mực nước của nó không cao hơn mức tối thiểu từ hàng xóm (nhưng ít nhất vẫn phải bằng chiều cao gốc của nó).

Sau vòng này, còn một vòng quét ngược từ **dưới phải lên trên trái** để đảm bảo cân bằng hai chiều.

2. **Vòng lặp từ dưới phải → lên trên trái**

   * `vols[i][j + 1]`: ô bên phải.

---

4. **Điều kiện cập nhật**

   if (vols[i][j] > val) {
       vols[i][j] = val;
       upt = true;

À mình hiểu rồi 👍 bạn muốn **minh hoạ trực quan cách mực nước dâng lên trong bài toán “Trapping Rain Water II”** (phiên bản 2D).
Mình sẽ giải thích theo từng bước, giống như bạn đang nhìn vào bản đồ độ cao (`heightMap`) và mực nước lưu trong `vols`.

---

### 1️⃣ Khởi tạo

* `vols[i][j]` ban đầu được set bằng chiều cao của biên (`boundary`).
* Tất cả ô bên trong (`1 ≤ i < m-1`, `1 ≤ j < n-1`) được gán bằng một giá trị rất lớn (`Integer.MAX_VALUE`) → nghĩa là ta giả định ban đầu nước có thể dâng **cực cao** bên trong.

👉 Trực quan: tưởng tượng ta dựng một cái hồ, ban đầu nước bên trong có thể đầy tràn, nhưng thực tế sẽ được “gọt xuống” nhờ các vòng lặp.

---

### 2️⃣ Quá trình cập nhật (while loop)

Trong vòng `while (upt) { ... }`:

* Mỗi lần duyệt qua, ta so sánh:

  ```java
  val = max(heightMap[i][j], min(vols[i+1][j], vols[i][j+1]))
  ```

  Có nghĩa:

  * `min(vols[i+1][j], vols[i][j+1])`: mực nước có thể giữ được phụ thuộc vào hàng xóm thấp hơn.
  * `max(heightMap[i][j], ...)`: nhưng nước không thể thấp hơn chính cái cột (tường) của ô đó.

* Nếu `vols[i][j] > val`, ta hạ nó xuống bằng `val`.
  Đồng thời set `upt = true` để cho biết **có sự thay đổi → cần duyệt lại**.

👉 Trực quan:
Nước ban đầu rất cao, nhưng dần dần “chảy” ra ngoài qua các ô biên thấp, từ từ hạ xuống mức cân bằng.

---

### 3️⃣ Khi không còn update (`upt = false`)

* Điều này nghĩa là toàn bộ lưới đã đạt trạng thái cân bằng:
  Mỗi `vols[i][j]` chính là mực nước cuối cùng có thể giữ tại ô đó.

👉 Trực quan:
Bạn tưởng tượng nước đã “dâng lên”, rồi từ từ chảy ra, cuối cùng dừng lại ở một mặt phẳng ổn định.

---

### 4️⃣ Tính kết quả

```java
res += vols[i][j] - heightMap[i][j];
```

* Nếu `vols[i][j] > heightMap[i][j]` → phần chênh lệch chính là **lượng nước giữ được tại ô đó**.
* Cộng dồn lại ra kết quả cuối cùng.

---

✅ **Hình dung bằng ví dụ nhỏ (2D mặt cắt):**

Giả sử heightMap:

```
[3, 3, 3, 3]
[3, 1, 1, 3]
[3, 3, 3, 3]
```

* Ban đầu: nước bên trong được set rất cao.
* Sau vài vòng cập nhật, nó hạ xuống:

  ```
  vols:
  [3, 3, 3, 3]
  [3, 3, 3, 3]
  [3, 3, 3, 3]
  ```
* Kết quả:
  Nước giữ = (3-1) + (3-1) = 4.

---

👉 Như vậy cái vòng `while(upt)` + `for` hai chiều chính là mô phỏng quá trình **nước chảy dần ra và ổn định mực nước**.

Bạn có muốn mình vẽ sơ đồ trực quan bằng **ASCII step-by-step** để thấy rõ hơn nước dâng và hạ từng vòng không?
À 😅 ý bạn hỏi cái **`-1`** trong phép tính `3 - 1` mình viết ở ví dụ đó hả?

👉 Ở đây nó không phải là **chỉ số -1** hay gì đặc biệt, mà đơn giản là:

* `vols[i][j] = 3` (mực nước cuối cùng ở ô đó)
* `heightMap[i][j] = 1` (chiều cao đất ở ô đó)

Khi ta tính `vols[i][j] - heightMap[i][j] = 3 - 1 = 2` → tức là ô đó giữ được 2 đơn vị nước.

Trong ví dụ có **2 ô trũng** đều là `1`, nên ta có:

```
(3 - 1) + (3 - 1) = 2 + 2 = 4
```

✅ Tóm lại: **`-1` ở đây chỉ là phép trừ để lấy chênh lệch giữa mực nước và chiều cao đất**, chứ không phải chỉ số mảng đâu.
