class Solution {
    public boolean exist(char[][] board, String word) {
        int m = board.length, n = board[0].length;
        if (word.length() == 0) return true;

        // 1) Count frequencies on board
        int[] cnt = new int[128];
        for (int i = 0; i < m; i++)
            for (int j = 0; j < n; j++)
                cnt[board[i][j]]++;

        // 2) Check feasibility and decide direction
        int[] need = new int[128];
        for (int k = 0; k < word.length(); k++) need[word.charAt(k)]++;
        for (int ch = 0; ch < 128; ch++)
            if (need[ch] > 0 && need[ch] > cnt[ch]) return false;

        // Rarity heuristic: start from less frequent end
        char first = word.charAt(0), last = word.charAt(word.length() - 1);
        if (cnt[first] > cnt[last]) {
            word = new StringBuilder(word).reverse().toString();
        }

        // 3) Backtracking
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (dfs(board, word, 0, i, j)) return true;
            }
        }
        return false;
    }
    
    private boolean dfs(char[][] b, String w, int k, int r, int c) {
        if (k == w.length()) return true;
        if (r < 0 || c < 0 || r >= b.length || c >= b[0].length) return false;
        if (b[r][c] != w.charAt(k)) return false;

        char saved = b[r][c];
        b[r][c] = '\0'; // mark visited

        // Try four directions
        if (dfs(b, w, k + 1, r + 1, c) ||
            dfs(b, w, k + 1, r - 1, c) ||
            dfs(b, w, k + 1, r, c + 1) ||
            dfs(b, w, k + 1, r, c - 1)) {
            b[r][c] = saved;
            return true;
        }

        b[r][c] = saved; // restore
        return false;
    }

}

### Ý nghĩa:

   * Duyệt toàn bộ bảng `board`.
   * `board[i][j]` là ký tự.
   * `cnt[board[i][j]]++` tăng số lần xuất hiện ký tự đó.

### Code:


* `word = "AAA"`

  * `need['A'] = 3` > `cnt['A'] = 2` → return false, vì không đủ A.

### 2️⃣ Rarity heuristic:

```java

if (cnt[first] > cnt[last]) {
    word = new StringBuilder(word).reverse().toString();
}
```

**Ví dụ:**

* `word = "FACE"`
* `cnt['F'] = 1`, `cnt['E'] = 2` → F hiếm hơn E → vẫn bắt đầu từ F


* `0` → **chỉ số ký tự hiện tại trong từ `word`** mà DFS đang kiểm tra. Ban đầu là `0` vì bắt đầu từ ký tự đầu tiên của từ.
* `i` → **hàng** trong bảng (`board[i][j]`) mà DFS bắt đầu kiểm tra.
* `j` → **cột** trong bảng (`board[i][j]`) mà DFS bắt đầu kiểm tra.

Nói cách khác, `dfs(board, word, 0, i, j)` nghĩa là:

> “Hãy thử tìm từ `word` bắt đầu từ ô `(i, j)` trong bảng, bắt đầu từ ký tự thứ `0` của từ.”

Ví dụ:

Bảng:

```
A B C
D E F
G H I
```

* `i = 1, j = 2` → ô `(1,2)` là ký tự `'F'`.
* `0` → kiểm tra ký tự đầu tiên của từ (`word.charAt(0)`).

DFS sẽ thử xem có thể hình thành từ bắt đầu từ `'F'` theo các hướng lên/xuống/trái/phải hay không.

Bạn có muốn mình minh họa **cách DFS đi qua các ô trên bảng** không?
Đúng rồi. Trong hàm `dfs(board, word, 0, i, j)`:

* `board` → **bảng ký tự** (mảng 2D `char[][]`) để DFS biết đi qua các ô nào.
* `word` → **từ cần tìm** để DFS so sánh ký tự hiện tại với ký tự ở ô `(i,j)`.

Hai tham số này **không thay đổi trong quá trình đệ quy**, chỉ có:

* `k` (chỉ số ký tự của từ) tăng dần,
* `r` và `c` (hàng và cột) thay đổi khi DFS đi sang các ô xung quanh.

Nói cách khác: `board` và `word` là **dữ liệu cố định** mà DFS dùng để tham chiếu, còn `0, i, j` là **vị trí và ký tự bắt đầu** cho lần kiểm tra hiện tại.

Nếu muốn, mình có thể vẽ **minh họa sơ đồ DFS trên bảng chữ cái** để bạn dễ hình dung cách `r` và `c` di chuyển. Bạn có muốn mình làm không?
