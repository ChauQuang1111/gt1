3354. Make Array Elements Equal to Zero
class Solution {
    public int countValidSelections(int[] nums) {
        int total = 0, ls = 0, cases = 0;
        for (int num : nums) total += num;

        for (int num : nums) {
            int rs = total - ls - num;
            if (num == 0) {
                if (ls == rs) {
                    cases += 2;
                } else if (ls == rs - 1 || ls - 1 == rs) {
                    cases += 1;
                }
            }
            ls += num;
        }
        return cases;
    }
}

Mục tiêu là:
Ta cần **đếm số cách hợp lệ (valid selections)** để chọn 1 vị trí `i` (vị trí chứa số `0`) sao cho **có thể làm toàn bộ mảng bằng 0** bằng cách trừ hoặc cộng 1 liên tục theo luật bài ra.

(Chi tiết bài gốc: chọn 1 vị trí bằng 0, rồi trừ dần các số bên trái hoặc cộng dần các số bên phải sao cho cân bằng về tổng.)

### 🔹 Biến trong thuật toán

* `ls` = tổng các phần tử bên **trái** vị trí hiện tại
* `rs` = tổng các phần tử bên **phải** vị trí hiện tại
* `num` = giá trị hiện tại của phần tử (ở đây đang xét các vị trí có `num == 0`)
* `cases` = tổng số cách hợp lệ tìm được

## 🧠 Mục tiêu của bài toán

Ta được cho một mảng `nums`, mỗi phần tử là 0 hoặc 1.
Ta cần **đếm số vị trí hợp lệ** (vị trí có giá trị = 0) mà nếu ta bắt đầu **"làm mảng thành toàn số 0"** từ vị trí đó, thì có thể thành công.

> Mỗi lần, ta có thể chọn vị trí bắt đầu là 0, rồi "trừ 1" hoặc "cộng 1" dần về hai phía để đưa mọi phần tử về 0.
> Điều kiện thành công là tổng bên trái và bên phải **phải cân bằng hoặc gần cân bằng (chênh 1 đơn vị)**.

---

## 🧩 Vì sao `+2` hoặc `+1`

### 🎯 Khi `ls == rs`  →  `cases += 2`

* Nghĩa là tổng phần **bên trái** và **bên phải** của vị trí 0 đang **cân bằng nhau** hoàn hảo.
* Trong trường hợp này, ta có **2 hướng hợp lệ để làm mảng về 0**:

  1. **Từ trái sang phải**
  2. **Từ phải sang trái**

=> Vì có **2 khả năng hợp lệ**, nên `cases += 2`.

---

### 🎯 Khi `|ls - rs| == 1`  →  `cases += 1`

* Nếu tổng bên trái và phải **chênh lệch đúng 1 đơn vị**, thì chỉ có **1 hướng hợp lệ** để đưa mảng về 0.

Ví dụ:

```
nums = [1, 0, 0]
```

Khi xét phần tử `nums[1] = 0`:

* Tổng trái `ls = 1`
* Tổng phải `rs = 0`
  → lệch nhau 1 đơn vị → chỉ có **1 cách hợp lệ** (giảm dần từ trái sang phải).

=> `cases += 1`

---

### 📊 Tóm tắt quy tắc

| Trường hợp | Ý nghĩa                | Cách hợp lệ                    | Cộng thêm     |                |      |
| ---------- | ---------------------- | ------------------------------ | ------------- | -------------- | ---- |
| `ls == rs` | Cân bằng hoàn hảo      | 2 hướng (trái→phải, phải→trái) | `+2`          |                |      |
| `          | ls - rs                | == 1`                          | Lệch 1 đơn vị | 1 hướng hợp lệ | `+1` |
| Khác       | Không thể làm cân bằng | 0                              | `+0`          |                |      |

Giả sử:

```
nums = [1, 0, 1]
```

* total = 2
* tại `num = 0`:

  * ls = 1
  * rs = 1
  * → `ls == rs` → `cases += 2`

→ có **2 cách hợp lệ**.

---

👉 Tóm lại:

* **+2** khi tổng hai bên **hoàn toàn bằng nhau** → 2 hướng có thể thực hiện.
* **+1** khi tổng hai bên **chênh nhau đúng 1** → chỉ 1 hướng hợp lệ.
* **0** nếu lệch nhiều hơn → không thể làm toàn bộ mảng bằng 0.
