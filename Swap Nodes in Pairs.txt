Swap Nodes in Pairs
class Solution {
    public ListNode swapPairs(ListNode head) {
        ListNode dummy = new ListNode(0);
        dummy.next = head;
        ListNode prev = dummy;

        while (head != null && head.next != null) {
            ListNode first = head;
            ListNode second = head.next;

            prev.next = second;
            first.next = second.next;
            second.next = first;

            prev = first;
            head = first.next;
        }

        return dummy.next;
    }
}
Rất hay — ba dòng này là **nền tảng chính** giúp thuật toán hoán đổi cặp nút (`swapPairs`) trong danh sách liên kết hoạt động trơn tru 💡
Cùng phân tích kỹ từng dòng nhé 👇

---

### 🧩 1️⃣ `ListNode dummy = new ListNode(0);`

👉 Tạo **một node giả (dummy node)** với giá trị bằng `0`.
Node này **không phải là một phần của dữ liệu thực**, mà chỉ giúp **xử lý dễ dàng hơn khi node đầu tiên bị thay đổi**.

**Ví dụ:**
Danh sách ban đầu:

```
1 -> 2 -> 3 -> 4
```

Sau khi hoán đổi, node đầu tiên **không còn là 1** mà trở thành `2`.
Nếu không có `dummy`, ta phải xử lý riêng trường hợp đặc biệt này — rất rườm rà.

Nhờ có node `dummy`, ta luôn có một “node đứng trước” để dễ dàng nối lại danh sách sau khi đổi cặp.

---

### 🧩 2️⃣ `dummy.next = head;`

👉 Cho node `dummy` **trỏ tới node đầu tiên thật sự** (tức là `head`).
Sau dòng này, danh sách sẽ trông như:

```
dummy(0) -> 1 -> 2 -> 3 -> 4
```

---

### 🧩 3️⃣ `ListNode prev = dummy;`

👉 Khai báo con trỏ `prev` trỏ đến `dummy`.
`prev` được dùng để **giữ vị trí của node đứng ngay trước cặp đang được hoán đổi**.

Sau mỗi lần hoán đổi 2 node, `prev` sẽ **di chuyển tới cuối cặp vừa hoán đổi** để chuẩn bị nối tiếp với cặp tiếp theo.

---

### 🔁 Ví dụ minh họa:

Giả sử danh sách là:

```
1 -> 2 -> 3 -> 4
```

* Ban đầu:

  ```
  dummy(0) -> 1 -> 2 -> 3 -> 4
  prev = dummy
  head = 1
  ```
* Sau khi hoán đổi `1` và `2`:

  ```
  dummy(0) -> 2 -> 1 -> 3 -> 4
  prev = 1
  head = 3
  ```

→ Vòng lặp tiếp tục với cặp `(3, 4)`.

---

### ✅ Kết quả cuối cùng:

```
dummy(0) -> 2 -> 1 -> 4 -> 3
```

Khi trả về `dummy.next`, ta bỏ qua node giả và thu được kết quả:

```
2 -> 1 -> 4 -> 3
```

---

Tóm lại:

| Dòng code                           | Vai trò chính                                |
| ----------------------------------- | -------------------------------------------- |
| `ListNode dummy = new ListNode(0);` | Tạo node giả giúp xử lý dễ hơn               |
| `dummy.next = head;`                | Liên kết node giả với danh sách thật         |
| `ListNode prev = dummy;`            | Giữ vị trí node đứng trước cặp đang hoán đổi |
Rất hay — đây là **phần lõi (core)** của thuật toán hoán đổi cặp nút trong danh sách liên kết 👇
Mình sẽ giải thích **từng dòng** để bạn hiểu rõ cách các con trỏ di chuyển và hoán đổi.

---

### 🧠 Bối cảnh trước vòng lặp:

Ta đang xử lý **danh sách liên kết đơn**, ví dụ:

```
dummy -> 1 -> 2 -> 3 -> 4
```

Ban đầu:

* `prev = dummy`
* `head = 1`

Mục tiêu: hoán đổi **1** và **2** → kết quả mong muốn:

```
dummy -> 2 -> 1 -> 3 -> 4
```

---

### 🔁 Bắt đầu vòng `while`

```java
while (head != null && head.next != null)
```

→ Lặp khi còn **ít nhất hai node** (`head` và `head.next`) để có thể hoán đổi.
Nếu chỉ còn 1 node hoặc danh sách rỗng thì không cần làm gì.

---

### 🔹 Dòng 1–2:

```java
ListNode first = head;
ListNode second = head.next;
```

→ Xác định **hai node liền kề cần đổi chỗ**.

Ví dụ:

```
first = 1
second = 2
```

---

### 🔹 Dòng 3:

```java
prev.next = second;
```

→ Nối node đứng trước cặp (`prev`) với node thứ hai (`second`).

Trước khi nối:

```
prev -> 1 -> 2 -> ...
```

Sau khi nối:

```
prev -> 2 -> ...
```

(bây giờ danh sách bắt đầu đổi hình dạng)

---

### 🔹 Dòng 4:

```java
first.next = second.next;
```

→ Node thứ nhất (`1`) bây giờ **phải trỏ tới node sau cặp**, tức là node `3`.

Kết quả:

```
1 -> 3
```

---

### 🔹 Dòng 5:

```java
second.next = first;
```

→ Node thứ hai (`2`) trỏ ngược lại node thứ nhất (`1`), hoàn tất việc **đổi chỗ**.

Giờ ta có:

```
2 -> 1 -> 3
```

---

### 🔹 Dòng 6–7:

```java
prev = first;
head = first.next;
```

→ Di chuyển con trỏ để chuẩn bị cho vòng hoán đổi tiếp theo:

* `prev` di chuyển đến cuối cặp vừa hoán đổi (`1`).
* `head` di chuyển đến node tiếp theo sau cặp (`3`).

Kết quả sau vòng đầu tiên:

```
dummy -> 2 -> 1 -> 3 -> 4
prev = 1
head = 3
```

✅ Tiếp theo, thuật toán sẽ hoán đổi `(3, 4)` theo cách tương tự.

---

### 🔚 Tóm tắt:

| Dòng code                             | Chức năng                     | Ví dụ     |
| ------------------------------------- | ----------------------------- | --------- |
| `first = head` / `second = head.next` | Lấy ra 2 node liền kề         | 1, 2      |
| `prev.next = second`                  | Nối node trước với node thứ 2 | dummy → 2 |
| `first.next = second.next`            | Node 1 trỏ sang node 3        | 1 → 3     |
| `second.next = first`                 | Node 2 trỏ ngược lại node 1   | 2 → 1     |
| `prev = first`                        | Cập nhật vị trí trước cặp mới | prev = 1  |
| `head = first.next`                   | Sang cặp tiếp theo            | head = 3  |

---

👉 Kết quả cuối cùng:

```
2 -> 1 -> 4 -> 3
```

Cấu trúc vòng lặp này giúp bạn hoán đổi từng cặp liền kề **mà không cần dùng mảng** hay **thay đổi giá trị**, chỉ đổi **liên kết (pointer)** — đúng tinh thần của bài “Swap Nodes in Pairs”.
