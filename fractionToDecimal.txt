fractionToDecimal
public static String fractionToDecimal(int numerator, int denominator) {
        // B1: Convert sang long để tránh tràn số
        long lnum = numerator, lden = denominator;

        // B2: Nếu tử số = 0 → kết quả là "0"
        if (lnum == 0) {
            return "0";
        }

        // B3: Nếu chia hết → trả về số nguyên
        if (lnum % lden == 0) {
            return Long.toString(lnum / lden);
        }

        // B4: StringBuilder để xây kết quả
        StringBuilder number = new StringBuilder();

        // B5: Xử lý dấu (chỉ âm nếu đúng 1 số âm)
        if ((lden < 0) ^ (lnum < 0)) {
            number.append('-');
        }

        // B6: Lấy trị tuyệt đối tử và mẫu
        lnum = Math.abs(lnum);
        lden = Math.abs(lden);

        // B7: Lấy phần nguyên
        number.append(lnum / lden);
        number.append('.'); // thêm dấu thập phân

        // B8: Rút gọn phân số bằng GCD
        long GCD = gcd(lnum, lden);
        lnum /= GCD;
        lden /= GCD;

        // B9: Lấy phần dư ban đầu để bắt đầu chia tiếp
        lnum %= lden;
        lnum *= 10;

        // B10: Kiểm tra mẫu chỉ có 2 và 5 → số thập phân hữu hạn
        int twos = 0, fives = 0;
        long temp = lden;

        while (temp % 2 == 0) {
            twos++;
            temp /= 2;
        }
        while (temp % 5 == 0) {
            fives++;
            temp /= 5;
        }

        // B11: Nếu mẫu chỉ có 2 và/hoặc 5
        if (temp == 1) {
            while (lnum != 0) {
                number.append(lnum / lden);
                lnum = (lnum % lden) * 10;
            }
        } else {
            // B12: Xử lý phần không lặp (do 2 và 5)
            int nonRepLen = Math.max(twos, fives);
            for (int i = 0; i < nonRepLen; i++) {
                number.append(lnum / lden);
                lnum = (lnum % lden) * 10;
            }

            // B13: Phát hiện chu kỳ bằng remainder
            long initRem = lnum;
            StringBuilder repeating = new StringBuilder();

            do {
                repeating.append(lnum / lden);
                lnum = (lnum % lden) * 10;
            } while (lnum != initRem);

            // B14: Thêm ngoặc cho phần lặp
            number.append('(').append(repeating.toString()).append(')');
        }

        // B15: Trả về kết quả cuối
        return number.toString();
    }

    // Hàm GCD (Ước chung lớn nhất)
    public static long gcd(long a, long b) {
        return (b == 0) ? a : gcd(b, a % b);
    }
}

### ❓ Tại sao chỉ kiểm tra 2 và 5?

* Trong **hệ thập phân (cơ số 10)**, mẫu số (denominator) chỉ tạo ra **số thập phân hữu hạn** nếu nó **chỉ có các thừa số nguyên tố là 2 và/hoặc 5**.
* Vì:

  * 10 = 2 × 5
  * Nên khi mẫu chỉ chứa 2 và 5 → ta có thể quy đồng mẫu thành một số dạng `10^k` → chia ra sẽ dừng.

---

### 📌 Ví dụ

* `1/2 = 0.5` ✅ (hữu hạn, vì mẫu chỉ có thừa số 2)
* `1/4 = 0.25` ✅ (mẫu = 2²)
* `1/5 = 0.2` ✅ (mẫu = 5)
* `1/8 = 0.125` ✅ (mẫu = 2³)
* `1/20 = 0.05` ✅ (mẫu = 2² × 5)

Nhưng:

* `1/3 = 0.(3)` ❌ (mẫu có thừa số nguyên tố 3, khác 2 và 5 → thập phân vô hạn lặp)
* `1/7 = 0.(142857)` ❌ (mẫu có thừa số nguyên tố 7)

---

### 1. Ý tưởng toán học

Muốn biết **phần thập phân hữu hạn (không lặp)** dài bao nhiêu chữ số, ta phải xét mẫu số sau khi bỏ hết các ước chung với tử số.

* Một phân số $\dfrac{a}{b}$ có **phần thập phân hữu hạn** nếu và chỉ nếu mẫu $b$ có dạng $2^m \cdot 5^n$.
* Khi đó, số chữ số **không lặp** trong phần thập phân chính là số mũ lớn nhất giữa $m$ và $n$.

  $$
  \text{nonRepLen} = \max(m, n)
  $$

---

### 2. Tại sao lấy max?

Vì ta cần biến mẫu số thành **bội của $10^k$**.

* Mà $10^k = 2^k \cdot 5^k$.
* Nếu $b = 2^m \cdot 5^n$, thì để thành mẫu số là lũy thừa của 10, ta cần thêm thừa số cho bên thiếu.

  * Nếu $m > n$, thì phải thêm $5^{m-n}$ để cân bằng. Lúc này $k = m$.
  * Nếu $n > m$, thì phải thêm $2^{n-m}$. Lúc này $k = n$.
  * Nói cách khác, $k = \max(m, n)$.

---

### 3. Ví dụ minh họa

* $\dfrac{1}{8} = \dfrac{1}{2^3}$
  → $m=3, n=0$.
  → $k = \max(3, 0) = 3$.
  → Kết quả: $1/8 = 0.125$ (3 chữ số không lặp).

* $\dfrac{1}{40} = \dfrac{1}{2^3 \cdot 5^1}$
  → $m=3, n=1$.
  → $k = \max(3, 1) = 3$.
  → Kết quả: $1/40 = 0.025$ (3 chữ số không lặp).

* $\dfrac{1}{200} = \dfrac{1}{2^3 \cdot 5^2}$
  → $m=3, n=2$.
  → $k = \max(3, 2) = 3$.
  → Kết quả: $1/200 = 0.005$ (3 chữ số không lặp).

### 1. Ý tưởng toán học (B13: phát hiện chu kỳ)

Khi chia số thập phân vô hạn tuần hoàn, **chu kỳ bắt đầu lặp lại khi số dư (remainder) lặp lại**.

* Giả sử ta đang tính $\dfrac{1}{7}$.
* Ta lấy `lnum % lden` để lấy số dư.
* Mỗi lần nhân số dư với 10 và chia tiếp, ta sinh ra 1 chữ số thập phân.
* Nếu một số dư đã từng xuất hiện → từ đây trở đi dãy chữ số sẽ lặp lại y chang → phát hiện được chu kỳ.

👉 Ở đây, code đơn giản hóa bằng cách:

* Ghi nhớ `initRem = lnum` (số dư đầu tiên).
* Sau đó chạy `do { … } while (lnum != initRem);`.
* Khi remainder quay lại bằng **initRem** → tức là một vòng lặp đã hoàn tất → tìm ra được chu kỳ.

---

### 2. Vòng `do { … } while (…)` hoạt động thế nào?

Khác với `while`, **`do … while` luôn chạy ít nhất một lần** trước khi kiểm tra điều kiện.

Cụ thể ở đây:

```java
do {
    repeating.append(lnum / lden);  // lấy chữ số thập phân tiếp theo
    lnum = (lnum % lden) * 10;      // cập nhật remainder
} while (lnum != initRem);
```

* Lần đầu tiên chắc chắn phải tính 1 chữ số thập phân từ remainder ban đầu.
* Sau đó cứ tiếp tục cho tới khi remainder = remainder ban đầu (`initRem`).
* Khi đó ta đã tìm xong **chu kỳ đầy đủ**.
