Swim in Rising Water
class Solution:
    def swimInWater(self, grid: List[List[int]]) -> int:
        n = len(grid)
        dirs = [(0, 1), (1, 0), (0, -1), (-1, 0)]

        visited = set()

        def dfs(r, c, max_time):
            # print(f"DFS from {(r, c)} with max time {max_time}")
            
            if r == n - 1 and c == n - 1:
                return True 
            
            visited.add((r, c))

            for dr, dc in dirs:
                nr, nc = dr + r, dc + c

                if 0 <= nr < n and 0 <= nc < n and (nr, nc) not in visited and grid[nr][nc] <= max_time:
                    # print(f"Exploring {(nr, nc)}")
                    if dfs(nr, nc, max_time):
                        return True 
        
            return False
        
        s = max(grid[0][0], grid[n-1][n-1])
        e = n * n - 1

        res = e

        while s <= e:
            m = (s + e) // 2
            visited = set()

            if dfs(0, 0, m):
                # print(f"Reachable with max time {m}")
                e = m - 1
                res = m
            else:
                s = m + 1
        
        return res

Bạn có muốn mình vẽ một **hình minh họa** mô phỏng quá trình nước dâng (tăng từ `0` → `n² - 1`) để bạn dễ hình dung hơn không?
Rất tốt 👍 — đây chính là **phần quan trọng nhất** của thuật toán: phần **binary search (tìm kiếm nhị phân)** kết hợp với DFS để tìm **mức nước nhỏ nhất có thể bơi tới đích**.
Giờ mình sẽ **giải thích từng dòng một** thật chi tiết, dễ hiểu nhé 👇

### 🧩 Toàn bộ đoạn code:

```python
res = e

while s <= e:
    m = (s + e) // 2
    visited = set()

    if dfs(0, 0, m):
        e = m - 1
        res = m
    else:
        s = m + 1

return res
```

---

### 💡 Bối cảnh:

Ta đang muốn tìm **mức nước nhỏ nhất (`t`)** sao cho có thể đi được từ `(0,0)` đến `(n-1,n-1)`.

* `s`: mực nước nhỏ nhất có thể thử (bắt đầu từ `max(grid[0][0], grid[n-1][n-1])`)
* `e`: mực nước cao nhất có thể (bằng `n*n - 1`)
* `dfs(0, 0, m)` sẽ kiểm tra **có đường đi được không** nếu mực nước hiện tại là `m`.

* Kiểm tra `dfs(0,0,6)` → **True**, nghĩa là:

  > Nước dâng đến 6 là đủ rồi, không cần tới 7.
* Giảm `e` tiếp:

  ```
  e = m - 1 = 5
  ```
* Cập nhật:

  ```
  res = 6
  ```

---

#### 🚫 Dừng:

* Giờ `s = 6, e = 5`, tức là `s > e`.
* Vòng lặp **kết thúc**.
* Kết quả cuối cùng là:

  ```
  res = 6
  ```

---

### 🧩 Kết luận:

| Ký hiệu       | Ý nghĩa                                       |
| ------------- | --------------------------------------------- |
| `m`           | Mực nước đang kiểm tra                        |
| `DFS kết quả` | Có thể đi tới đích với mực nước này không     |
| `Điều chỉnh`  | Cập nhật lại giới hạn tìm kiếm (`s` hoặc `e`) |
| `res`         | Kết quả nhỏ nhất tạm thời tìm được            |

---

👉 Cuối cùng, **`res = 6`** nghĩa là:

> Khi nước dâng đến **6**, bạn có thể bơi từ `(0,0)` đến `(n-1,n-1)` — và **không cần mực nước cao hơn nữa**.
