966. Vowel Spellchecker(14/09/2025)
class Solution {
    public String[] spellchecker(String[] wordlist, String[] queries) {
        int m = wordlist.length, n = queries.length;
        String[] res = new String[n];
        Map<String, Integer> caseSense = new HashMap<>();
        Map<String, Integer> caseInsense = new HashMap<>();
        Map<String, Integer> vowelErrors = new HashMap<>();
        for (int i = m - 1; i >= 0; i--) {
            String word = wordlist[i];
            caseSense.put(word, i);
            String lowerCase = word.toLowerCase();
            char[] vowelRepArr = lowerCase.toCharArray();
            for (int j = 0; j < vowelRepArr.length; j++) {
                if (vowelRepArr[j] == 'e' || vowelRepArr[j] == 'i' || vowelRepArr[j] == 'o' || vowelRepArr[j] == 'u') {
                    vowelRepArr[j] = 'a';
                }
            }
            caseInsense.put(lowerCase, i);
            vowelErrors.put(new String(vowelRepArr), i);
        }
        for (int i = 0; i < n; i++) {
            String word = queries[i];
            if (caseSense.containsKey(word)) {
                res[i] = word;
                continue;
            }

            String lowerCase = word.toLowerCase();
            if (caseInsense.containsKey(lowerCase)) {
                res[i] = wordlist[caseInsense.get(lowerCase)];
                continue;
            }

            char[] vowelRepArr = lowerCase.toCharArray();
            for (int j = 0; j < vowelRepArr.length; j++) {
                if (vowelRepArr[j] == 'e' || vowelRepArr[j] == 'i' || vowelRepArr[j] == 'o' || vowelRepArr[j] == 'u') {
                    vowelRepArr[j] = 'a';
                }
            }
            String vowelRepStr = new String(vowelRepArr);
            if (vowelErrors.containsKey(vowelRepStr)) {
                res[i] = wordlist[vowelErrors.get(vowelRepStr)];
                continue;
            }
            res[i] = "";
        }

        return res;

    }
}

# 📝 Vowel Spellchecker – Mini Cheat Sheet

---

## 1️⃣ Flowchart logic

```
Query q
   │
   ▼
Exact match? (caseSense.containsKey(q))
   │Yes → res[i] = q
   │No
   ▼
Case-insensitive? (caseInsense.containsKey(q.toLowerCase()))
   │Yes → res[i] = wordlist[caseInsense.get(q.toLowerCase())]
   │No
   ▼
Vowel-error? (devowel(q.toLowerCase()) in vowelErrors)
   │Yes → res[i] = wordlist[vowelErrors.get(devowel(q.toLowerCase()))]
   │No → res[i] = ""
```

---

## 2️⃣ Pseudo code Java

```java
// 1. Build maps
Set<String> exact = new HashSet<>();
Map<String, Integer> caseMap = new HashMap<>();
Map<String, Integer> vowelMap = new HashMap<>();

for (int i = wordlist.length-1; i >= 0; i--) {
    String word = wordlist[i];
    exact.add(word);
    caseMap.put(word.toLowerCase(), i);
    vowelMap.put(devowel(word.toLowerCase()), i);
}

// 2. Process queries
for (int i = 0; i < queries.length; i++) {
    String q = queries[i];

    if (exact.contains(q)) { res[i] = q; continue; }
    if (caseMap.containsKey(q.toLowerCase())) { res[i] = wordlist[caseMap.get(q.toLowerCase())]; continue; }
    if (vowelMap.containsKey(devowel(q.toLowerCase()))) { res[i] = wordlist[vowelMap.get(devowel(q.toLowerCase()))]; continue; }

    res[i] = "";
}

// helper
String devowel(String s) {
    return s.replace('e','a').replace('i','a').replace('o','a').replace('u','a');
}
```

---

## 3️⃣ Key concepts

| Concept                    | Description                                                   |
| -------------------------- | ------------------------------------------------------------- |
| **Exact match**            | Query matches wordlist exactly (case + letters).              |
| **Case-insensitive match** | Ignore letter case, return **first occurrence** in wordlist.  |
| **Vowel-error match**      | Replace e,i,o,u → a, return **first occurrence** in wordlist. |
| **No match**               | Return `""`.                                                  |

---

## 4️⃣ Mini example

```java
wordlist = ["KiTe","Hare"];
queries  = ["kite","HARE","kito","xyz"];
```

| Query  | Match Type       | Output |
| ------ | ---------------- | ------ |
| "kite" | Case-insensitive | "KiTe" |
| "HARE" | Case-insensitive | "Hare" |
| "kito" | Vowel-error      | "KiTe" |
| "xyz"  | No match         | ""     |

* `devowel("kito")` → `"kata"` → lookup `vowelMap` → index 0 → "KiTe"

## 5️⃣ Quick memory tip

**Lookup order:**

```
Exact → Case-insensitive → Vowel-error → ""
```

**Maps:**

1. `exact` → exact match
2. `caseMap` → lowercase → index
3. `vowelMap` → devowel(lowercase) → index
