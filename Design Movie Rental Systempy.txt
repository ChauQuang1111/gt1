```python
def drop(self, shop: int, movie: int) -> None:
    self.rented.discard((shop, movie))
```

### 1️⃣ Ý nghĩa đoạn code

* `drop` nghĩa là khách hàng **trả lại phim** (kết thúc việc thuê).
* Trong class này:

  * `self.rented` là một `set` chứa các bộ phim đang được thuê, mỗi phần tử có dạng `(shop, movie)`.
* Khi gọi `drop(shop, movie)`, ta muốn **xóa (shop, movie) khỏi tập `self.rented`**.

👉 Dùng `discard` để xóa.

---

### 2️⃣ `.discard` là gì?

* `.discard` là **hàm có sẵn của kiểu `set` trong Python** (không phải tự định nghĩa).
* Công dụng: Xóa một phần tử trong `set`.
* **Điểm khác biệt** với `.remove`:

  * `.discard(x)` sẽ **không báo lỗi** nếu `x` không tồn tại trong `set`.
  * `.remove(x)` sẽ **báo lỗi KeyError** nếu `x` không tồn tại.

---

### 3️⃣ Ví dụ minh họa

```python
s = {1, 2, 3}

s.discard(2)   # xóa 2, s = {1, 3}
s.discard(5)   # không có 5, nhưng cũng KHÔNG báo lỗi → s = {1, 3}

s.remove(1)    # xóa 1, s = {3}
s.remove(10)   # LỖI: KeyError vì 10 không có trong set
```

### 1️⃣ Code gốc

```python
def report(self) -> List[List[int]]:
    rented_list = []
    for shop, movie in self.rented:
        price = self.available[(shop, movie)]
        rented_list.append((price, shop, movie))

    rented_list.sort()
    return [[shop, movie] for price, shop, movie in rented_list[:5]]
```

---

### 2️⃣ Ý nghĩa từng bước

1. **Tạo danh sách tạm thời để chứa phim đang thuê**

   ```python
   rented_list = []
   ```

   Đây sẽ là list chứa các bộ 3 `(price, shop, movie)`.

2. **Duyệt qua tất cả các phim đang thuê**

   ```python
   for shop, movie in self.rented:
       price = self.available[(shop, movie)]
       rented_list.append((price, shop, movie))
   ```

   * `self.rented` là `set` chứa các bộ phim đã thuê dạng `(shop, movie)`.
   * Với mỗi `(shop, movie)`, lấy giá `price` từ `self.available[(shop, movie)]`.
   * Thêm bộ `(price, shop, movie)` vào `rented_list`.
     → Lý do đưa `price` lên đầu: để dễ **sắp xếp theo giá trước tiên**.

3. **Sắp xếp danh sách phim đã thuê**

   ```python
   rented_list.sort()
   ```

   * Python mặc định sắp xếp tuple theo **thứ tự từ trái qua phải**.
   * Nghĩa là `(price, shop, movie)` sẽ được sắp theo:

     1. Giá **tăng dần**
     2. Nếu giá bằng nhau → shop **tăng dần**
     3. Nếu shop cũng bằng nhau → movie **tăng dần**

4. **Lấy ra tối đa 5 kết quả đầu tiên**

   ```python
   return [[shop, movie] for price, shop, movie in rented_list[:5]]
   ```

   * `rented_list[:5]` nghĩa là **lấy từ đầu đến 5 phần tử đầu tiên** (nếu có ít hơn 5 thì lấy hết).
   * Sau đó chỉ trả về `[shop, movie]` (không cần giá vì đề chỉ yêu cầu shop + movie).

### 3️⃣ Ví dụ minh họa

Giả sử:

```python
self.rented = {(0, 1), (1, 2), (2, 1)}
self.available = {(0,1): 5, (1,2): 7, (2,1): 5}
```

Thì:

* `rented_list` sau vòng for =

  ```
  [(5, 0, 1), (7, 1, 2), (5, 2, 1)]
  ```
* Sau khi `.sort()` =

  ```
  [(5, 0, 1), (5, 2, 1), (7, 1, 2)]
  ```
* `rented_list[:5]` = giữ nguyên (vì có 3 phần tử thôi).
* Kết quả trả về =

  ```
  [[0, 1], [2, 1], [1, 2]]
  ```

---

👉 Vậy `[:5]` có nghĩa là **giới hạn kết quả tối đa 5 bản ghi đầu tiên**, đúng yêu cầu đề bài: *“trả về tối đa 5 phim đang thuê theo thứ tự ưu tiên”*.
