public static int birthdayCakeCandles(List<Integer> candles) {
    int max = Integer.MIN_VALUE;
    int count = 0;

    for (int height : candles) {
        if (height > max) {
            max = height;   // found a new tallest candle
            count = 1;      // reset count to 1
        } else if (height == max) {
            count++;        // another candle with same tallest height
        }
    }

    return count;
}
Ok 👍 mình giải thích chi tiết thuật toán trong hàm `birthdayCakeCandles`:


## 💻 Code rút gọn

```java
public static int birthdayCakeCandles(List<Integer> candles) {
    int max = Collections.max(candles);              // tìm chiều cao lớn nhất
    return Collections.frequency(candles, max);      // đếm số lần max xuất hiện
}
```

👉 Bạn muốn mình phân tích thử **độ phức tạp** và tình huống nên dùng **cách 1** hay **cách 2** không?
Good question 👌, mình giải thích rõ nhé:

---

### Khi gặp **một cây nến cao hơn `max`**

Ví dụ: `candles = [2, 3, 1]`

Bắt đầu:

* `max = -∞`, `count = 0`

**Lần 1:** gặp `2`

* `2 > -∞` → cập nhật `max = 2`
* Đây là **cây nến cao nhất đầu tiên** → `count = 1`

**Lần 2:** gặp `3`

* `3 > 2` → cập nhật `max = 3`
* Vì đây là **cây nến cao nhất mới**, tất cả nến trước đó đều thấp hơn, nên phải **reset lại count = 1** (tính lại từ đầu, chỉ có nến này cao nhất thôi).

👉 Nếu dùng `count++` ở đây thì sai, vì nó sẽ cộng dồn số nến thấp hơn trước đó.

---

### Khi gặp **cây nến bằng với `max`**

Ví dụ tiếp: `candles = [2, 3, 1, 3]`

* Sau 3 vòng, ta có `max = 3`, `count = 1`
* Lần 4 gặp `3`

  * `3 == max` → nghĩa là có thêm 1 cây bằng chiều cao lớn nhất → `count++` → `count = 2`.

---

### ✅ Tóm lại

* **`count = 1`** khi tìm thấy **một chiều cao mới lớn hơn tất cả** → reset vì trước đó không còn ý nghĩa.
* **`count++`** khi gặp thêm nến có chiều cao bằng với `max` hiện tại.

---

👉 Nếu lúc nào cũng dùng `count++`, thì ví dụ `[2, 3]` sẽ ra:

* gặp `2`: `count = 1`
* gặp `3`: `max = 3` nhưng `count++` = 2 ❌ (sai, vì chỉ có 1 cây cao nhất thôi).

Bạn có muốn mình làm một bảng **so sánh kết quả nếu dùng `count = 1` vs `count++`** để bạn dễ hình dung hơn không?

## 🔎 Thuật toán làm gì?

* Tìm chiều cao **cao nhất** của nến (`max`).
* Đếm có **bao nhiêu cây nến bằng chiều cao đó** (`count`).

## 📌 Vì sao không viết một điều kiện `if (height == max)`?

Giả sử chỉ viết như này:

```java
if (height == max) {
    count++;
}
```

👉 Sai! Vì:

* Lúc bắt đầu `max = Integer.MIN_VALUE`.
* Khi gặp **nến cao đầu tiên**, ta **chưa biết `max` là bao nhiêu**, nên phải cập nhật lại `max` và reset `count = 1`.
* Nếu chỉ dùng `==`, thì nến cao đầu tiên **sẽ không bao giờ được tính**.

## 📖 Cách hoạt động (chuẩn)

### Code:

```java
if (height > max) {
    max = height;   // tìm thấy nến cao hơn
    count = 1;      // reset số lượng vì đây là nến cao nhất đầu tiên
} else if (height == max) {
    count++;        // thêm 1 nến có cùng chiều cao
}
```

---

### Ví dụ `[4, 4, 1, 3, 4]`

| height | max hiện tại | count hiện tại | So sánh | Hành động               | max mới | count mới |
| ------ | ------------ | -------------- | ------- | ----------------------- | ------- | --------- |
| 4      | -∞           | 0              | 4 > -∞  | cập nhật max=4, count=1 | 4       | 1         |
| 4      | 4            | 1              | 4 == 4  | count++                 | 4       | 2         |
| 1      | 4            | 2              | 1 < 4   | bỏ qua                  | 4       | 2         |
| 3      | 4            | 2              | 3 < 4   | bỏ qua                  | 4       | 2         |
| 4      | 4            | 2              | 4 == 4  | count++                 | 4       | 3         |

👉 Kết quả: có **3 cây nến cao nhất**.

## ✅ Tóm gọn

* `if (height > max)` → dùng để **tìm chiều cao cao nhất mới** và reset lại `count = 1`.
* `else if (height == max)` → dùng để **cộng thêm** khi gặp nhiều cây nến có cùng chiều cao cao nhất.

Nếu bỏ `if (height > max)` thì ta **không thể cập nhật `max` và reset lại count**, dẫn đến kết quả sai.
