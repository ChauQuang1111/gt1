Count Unguarded Cells in the Grid
class Solution:
    def countUnguarded(self, m: int, n: int, guards: List[List[int]], walls: List[List[int]]) -> int:
        grid = [[0]*n for _ in range(m)]
        for r,c in walls:
            grid[r][c] = 1
        for r,c in guards:
            grid[r][c] = 1
        for r,c in guards:
            u = r-1
            while u >= 0 and grid[u][c] != 1:
                grid[u][c] = 2
                u -= 1
            d = r+1
            while d < m and grid[d][c] != 1:
                grid[d][c] = 2
                d += 1
            l = c-1
            while l >= 0 and grid[r][l] != 1:
                grid[r][l] = 2
                l -= 1
            ri = c+1
            while ri < n and grid[r][ri] != 1:
                grid[r][ri] = 2
                ri += 1
        unguarded = 0
        for r in range(m):
            for c in range(n):
                if grid[r][c] == 0:
                    unguarded += 1
        return unguarded

Rất hay 👏 — hai dòng này là **phần quan trọng để thiết lập trạng thái ban đầu của lưới (grid)**,
mình sẽ giải thích chi tiết cho bạn hiểu **vì sao cần làm như vậy và ý nghĩa từng dòng** nhé 👇

### 🧩 Bối cảnh trước hết

Trong bài này, bạn đang mô phỏng một **bản đồ lưới `m × n`** —
mỗi ô có thể là **trống**, **tường (wall)**, hoặc **bảo vệ (guard)**.

Bạn khởi tạo:

```python
grid = [[0] * n for _ in range(m)]
```

→ Tất cả các ô ban đầu có giá trị `0`, nghĩa là “**ô trống, chưa bị giám sát**”.

---

### ⚙️ Dòng 1:

```python
for r, c in walls:
    grid[r][c] = 1
```

🔹 Ý nghĩa:

* `walls` là danh sách các tọa độ (r, c) của tường trong lưới.
* Mỗi lần lặp, ta **đặt giá trị ô tại vị trí (r, c) bằng 1** để đánh dấu “**đây là tường**”.

🔹 Lý do:

* Ô là tường thì ánh nhìn của guard **không thể đi qua**,
  nên ta cần biết chỗ nào là tường để **dừng khi chiếu hướng**.

🧱 Ví dụ:

```
walls = [[0, 1]]
→ grid[0][1] = 1

Lưới:
0 1 0
0 0 0
0 0 0
```

=> Ô (0,1) là tường.

---

### ⚙️ Dòng 2:

```python
for r, c in guards:
    grid[r][c] = 1
```

🔹 Ý nghĩa:

* `guards` là danh sách các tọa độ (r, c) của các bảo vệ.
* Mỗi guard cũng **chiếm một ô**, không phải ô trống,
  nên ta **đặt `grid[r][c] = 1`** (đánh dấu là bị chặn).

🔹 Lý do:

* Guard **không thể giám sát qua chính mình**,
  và **không thể giám sát xuyên qua guard khác**.
  Vì vậy, guard được đánh dấu cùng giá trị với tường (`1`),
  để khi chiếu hướng gặp `1` → **dừng lại**.

🧍 Ví dụ:

```
guards = [[1, 1]]
→ grid[1][1] = 1

Lưới sau khi đánh dấu cả wall và guard:
0 1 0
0 1 0
0 0 0
```

---

### 🧠 Tóm tắt ý nghĩa:

| Giá trị `grid[r][c]` | Ý nghĩa          | Mục đích                |
| -------------------- | ---------------- | ----------------------- |
| `0`                  | Ô trống          | Có thể bị giám sát      |
| `1`                  | Tường hoặc Guard | Cản đường, dừng chiếu   |
| `2`                  | Ô bị giám sát    | Đã được guard nhìn thấy |

---

👉 Hai vòng `for` này giúp bạn **xây dựng bản đồ ban đầu**,
trước khi guard bắt đầu “nhìn” xung quanh 4 hướng.
Nếu không có bước này, guard có thể “nhìn xuyên tường hoặc xuyên guard khác”,
và kết quả sẽ sai.

---

Rất tốt 👍 — đoạn code bạn hỏi chính là **trái tim của thuật toán**, nơi các guard “quét tầm nhìn” trong 4 hướng (trên, dưới, trái, phải).
Mình sẽ **giải thích chi tiết từng dòng** để bạn hiểu rõ cơ chế hoạt động 👇

### 🎯 Mục tiêu đoạn code này

Từ vị trí của **mỗi guard (r, c)**, ta **quét ra 4 hướng**:

* **Trên** (up)
* **Dưới** (down)
* **Trái** (left)
* **Phải** (right)

và đánh dấu các ô mà guard có thể nhìn thấy là `2`
(trừ khi tầm nhìn bị **tường hoặc guard khác** chặn lại).

---

### ⚙️ Cấu trúc chung

```python
for r, c in guards:   # duyệt từng guard trong danh sách
    # hướng lên
    ...
    # hướng xuống
    ...
    # hướng trái
    ...
    # hướng phải
    ...
```

---

### 🟩 1️⃣ Hướng **lên**:

```python
u = r - 1
while u >= 0 and grid[u][c] != 1:
    grid[u][c] = 2
    u -= 1
```

#### Giải thích:

* Bắt đầu từ ô **phía trên guard**, tức `(r-1, c)`.
* `while u >= 0` đảm bảo không vượt ra ngoài biên trên của lưới.
* `grid[u][c] != 1` nghĩa là **chưa gặp tường hay guard khác** → tiếp tục quét.
* Mỗi ô guard nhìn thấy được gán `grid[u][c] = 2` (ô bị giám sát).
* `u -= 1`: di chuyển lên tiếp 1 hàng (vì “hướng lên” → chỉ số hàng giảm).

🧭 Dừng lại khi:

* Ra khỏi lưới (`u < 0`), hoặc
* Gặp tường/guard (`grid[u][c] == 1`).

---

### 🟨 2️⃣ Hướng **xuống**:

```python
d = r + 1
while d < m and grid[d][c] != 1:
    grid[d][c] = 2
    d += 1
```

#### Giải thích:

* Bắt đầu tại ô ngay **dưới guard**: `(r+1, c)`
* `while d < m` để không vượt quá hàng cuối cùng.
* `grid[d][c] != 1`: chưa bị chặn → tiếp tục quét.
* Đánh dấu là `2` (bị giám sát).
* `d += 1`: tiếp tục đi xuống.

🧱 Dừng khi:

* Gặp tường hoặc guard khác (`== 1`)
* Ra khỏi lưới (`d == m`)

---

### 🟦 3️⃣ Hướng **trái**:

```python
l = c - 1
while l >= 0 and grid[r][l] != 1:
    grid[r][l] = 2
    l -= 1
```

#### Giải thích:

* Bắt đầu từ ô **bên trái guard**: `(r, c-1)`
* `while l >= 0`: không vượt khỏi biên trái.
* `grid[r][l] != 1`: chưa bị tường/guard chắn.
* `grid[r][l] = 2`: đánh dấu bị giám sát.
* `l -= 1`: đi tiếp sang trái.

---

### 🟥 4️⃣ Hướng **phải**:

```python
ri = c + 1
while ri < n and grid[r][ri] != 1:
    grid[r][ri] = 2
    ri += 1
```

#### Giải thích:

* Bắt đầu từ ô **bên phải guard**: `(r, c+1)`
* `while ri < n`: không vượt khỏi biên phải.
* `grid[r][ri] != 1`: nếu chưa gặp tường hoặc guard khác thì tiếp tục.
* `grid[r][ri] = 2`: đánh dấu ô bị giám sát.
* `ri += 1`: đi tiếp sang phải.

### 🧮 Ví dụ minh họa

Giả sử:

```

guards = [[1, 1]]

```

* Lên: (0,1)

* Phải: (1,2) (đến (1,3) dừng lại vì wall)

```
0 2 0 0
0 2 0 0
```

| Biến                       | Ý nghĩa                               |
| -------------------------- | ------------------------------------- |
| `r, c`                     | Tọa độ guard hiện tại                 |
| `u, d, l, ri`              | Dòng / cột di chuyển khi quét 4 hướng |
| `grid[r][c] == 1`          | Tường hoặc guard → dừng               |

### 🧩 Ý nghĩa của các giá trị trong `grid`

Trong bài này, ta thường quy ước các giá trị trong ma trận `grid` như sau:

| Giá trị | Ý nghĩa                                                    |
| :------ | :--------------------------------------------------------- |
| `0`     | Ô **trống**, chưa bị giám sát, không có tường hay lính gác |
| `1`     | Ô có **tường hoặc guard** (chặn tầm nhìn)                  |
| `2`     | Ô **bị giám sát** – tức guard có thể “nhìn thấy” ô này     |

---

### 🔍 Vậy tại sao lại gán `2`?

Khi guard **nhìn được tới một ô**, nghĩa là ô đó **không còn “an toàn”**, nhưng nó **không phải là tường hay guard**.
Ta cần phân biệt ba trạng thái:

1. `1`: không thể nhìn xuyên qua (tường/guard),
2. `2`: có thể nhìn tới (đã bị giám sát),
3. `0`: vẫn còn trống, chưa bị ai giám sát.

### 💡 Ví dụ nhỏ minh họa

Giả sử lưới 3x3, có một guard ở giữa `(1,1)`
Ban đầu:

```
0 0 0
0 1 0
0 0 0
```

Sau khi guard “quét” 4 hướng, ta được:

```
0 2 0
2 1 2
0 2 0
```

→ Những ô có giá trị `2` là **bị giám sát** (guard nhìn thấy được).
Chỉ các ô còn `0` mới là **“unguarded”**, ta sẽ đếm các ô đó cuối cùng.

---

👉 **Tóm lại:**

* `0` = chưa bị giám sát
* `1` = guard hoặc tường
* `2` = bị giám sát bởi guard

Nếu muốn, mình có thể giúp bạn đổi cách biểu diễn cho dễ hiểu hơn (ví dụ: `'G'`, `'W'`, `'S'`, `'U'` thay vì số).
Bạn có muốn xem phiên bản đó không?
Rất hay 👍 — đây chính là **bước cuối cùng** của thuật toán, nơi ta **đếm số ô không bị giám sát (unguarded)**.
Cùng phân tích kỹ từng dòng nhé 👇

### 🧩 Đoạn code:

```python
unguarded = 0
for r in range(m):
    for c in range(n):
        if grid[r][c] == 0:
            unguarded += 1
return unguarded
```

---

### 🧠 Giải thích chi tiết:

#### ✅ `unguarded = 0`

* Khởi tạo biến đếm `unguarded` để **đếm số ô chưa bị giám sát** trong lưới (`grid`).
* Ban đầu là 0 vì chưa đếm ô nào.

---

#### ✅ `for r in range(m):`

* Duyệt qua từng **hàng (row)** của ma trận `grid`.
* `m` là số hàng.

---

#### ✅ `for c in range(n):`

* Duyệt qua từng **cột (column)** của mỗi hàng.
* `n` là số cột.

=> Hai vòng `for` kết hợp lại giúp ta **duyệt qua toàn bộ ô trong lưới** (tức là mọi vị trí `(r, c)`).

---

#### ✅ `if grid[r][c] == 0:`

* Kiểm tra xem ô hiện tại `(r, c)` **có giá trị là 0 hay không**.
* Như đã giải thích ở trên:

  * `0` = ô **trống**, không có guard, không có tường, **chưa bị giám sát**.

=> Nếu đúng, nghĩa là ô đó là “**unguarded cell**”.

---

#### ✅ `unguarded += 1`

* Tăng biến `unguarded` lên 1 mỗi khi tìm được ô không bị giám sát.

---

#### ✅ `return unguarded`

* Sau khi duyệt xong toàn bộ `m * n` ô, ta trả về tổng số ô **chưa bị giám sát** (kết quả của bài toán).

### 💡 Ví dụ minh họa:

Giả sử lưới 3×3 sau khi xử lý guard và wall như sau:


| Ký hiệu | Nghĩa              |
| ------- | ------------------ |
| 0       | Ô chưa bị giám sát |
| 1       | Guard hoặc tường   |
| 2       | Ô bị giám sát      |

Ta sẽ duyệt từng ô, và thấy rằng có **3 ô** có giá trị `0` →
`unguarded = 3`.

✅ **Kết quả trả về:** `3`
