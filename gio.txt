### 📌 Ý nghĩa

* Hàm `substring(8)` sẽ **cắt chuỗi từ vị trí index = 8 trở đi**.
* Trong định dạng giờ 12h, chuỗi luôn có dạng `"HH:mm:ssAM"` hoặc `"HH:mm:ssPM"`, độ dài **10 ký tự**.

Ví dụ:

```
"07:05:45PM"
 ↑0123456789   (chỉ số index)
```

* `s.substring(8)` → lấy từ index 8 đến hết.

  * Index 8 = `'P'`
  * Index 9 = `'M'`
  * Kết quả: `"PM"`

---

### 📝 Các ví dụ cụ thể

1. `"07:05:45PM"`

   * `substring(8)` → `"PM"`

2. `"12:00:00AM"`

   * `substring(8)` → `"AM"`

3. `"01:59:59AM"`

   * `substring(8)` → `"AM"`

### 🚩 Xử lý AM/PM

#### Trường hợp `"AM"`

```java
if (period.equals("AM")) {
    if (hour == 12) {
        hour = 0;  // 12 AM -> 00
    }
}
```

* Nếu là `"AM"`:

  * `01 AM → 01`, `02 AM → 02` … giữ nguyên.
  * Riêng `12 AM` là nửa đêm → đổi thành `00`.

---

#### Trường hợp `"PM"`

```java
else { // PM
    if (hour != 12) {
        hour += 12;  // e.g. 1PM -> 13
    }
}
```

* Nếu là `"PM"`:

  * `01 PM → 13`, `02 PM → 14` … cộng thêm 12.
  * Riêng `12 PM` (trưa) → giữ nguyên 12.

---

### 🖨️ Format lại chuỗi

```java
return String.format("%02d%s", hour, minutesSeconds);
```

* `%02d` → in số nguyên có 2 chữ số (thêm `0` nếu cần).
* Ghép với `minutesSeconds`.
