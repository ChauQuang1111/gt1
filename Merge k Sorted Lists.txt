23. Merge k Sorted Lists
class Solution {
   
    public static ListNode mergeKLists(ListNode[] lists) {
        if(lists.length == 0) return null;

        int max = Integer.MIN_VALUE; 
        int min = Integer.MAX_VALUE;
        

            for (ListNode nodeRow : lists) {
                  for(ListNode head = nodeRow; head != null; head = head.next) {
                        min = Math.min(min, head.val);
                        max = Math.max(max, head.val);
                  } 
            }

        min = Math.abs(min);
        int freq[] = new int[max + min + 1];

            for (ListNode nodeRow : lists) {
                  for(ListNode head = nodeRow; head != null; head = head.next) {
                        freq[head.val + min]++;
                  } 
            }

        ListNode dummy = new ListNode(-1);
        ListNode temp = dummy;

            for (int i = 0; i < freq.length; i++) {
                    if (freq[i] > 0) {
                        int val = i - min;
                            while (freq[i] --> 0) {
                                    temp.next = new ListNode(val);
                                    temp = temp.next;
                            }
                    }
            }

        return dummy.next;
    }
}

### 2. Tại sao `head.val + min`?

⇒ Mảng `freq` cần có **kích thước = max + min + 1** để chứa đủ mọi index từ 0 đến `max+min`.

Trong mảng, **chỉ số (index)** phải luôn là **số nguyên không âm**. Nhưng trong linked list, giá trị (`val`) có thể là **âm, 0, hoặc dương**.

---

### Vì sao `+ min`?

Ví dụ:
Danh sách có giá trị: `[-3, -1, 0, 2, 5]`

* Giá trị nhỏ nhất (**min**) = `-3`
* Giá trị lớn nhất (**max**) = `5`

Nếu bạn tạo mảng `freq[max+1] = freq[6]`, bạn **không thể lưu `-3` ở chỉ số -3** → vì mảng không có index âm.

👉 Cách giải quyết: **Dời tất cả giá trị sang dương**.

* Công thức: `freq[value - min]++` hoặc `freq[value + |min|]++`

Ví dụ:

```
value = -3 → index = -3 - (-3) = 0
value = -1 → index = -1 - (-3) = 2
value =  0 → index = 0 - (-3) = 3
value =  2 → index = 2 - (-3) = 5
value =  5 → index = 5 - (-3) = 8
```

---

### Vì sao `max + min + 1`?

Sau khi dịch sang dương, ta cần biết **kích thước mảng tối thiểu**.

* Khoảng giá trị từ `min` → `max` có tổng số phần tử là:

  ```
  (max - min + 1)
  ```

* Nhưng trong code bạn viết:

  ```java
  min = Math.abs(min);
  int freq[] = new int[max + min + 1];
  ```

  tức là bạn **dùng |min| thay vì (−min)**.

Ví dụ:

* `min = -3 → Math.abs(min) = 3`
* `max = 5`
* `max + min + 1 = 5 + 3 + 1 = 9`
* Mảng `freq` sẽ có index từ `0..8`, vừa đủ để chứa giá trị từ `-3..5`. ✅

👉 Tóm lại:

* `+min` (hay `+|min|`) là để **dời giá trị âm sang dương** làm index.
* `max + min + 1` chính là **độ dài mảng**, đủ để chứa tất cả giá trị từ `min` đến `max` sau khi đã dịch.

    if (freq[i] > 0) {

        while (freq[i]-- > 0) {  // thêm freq[i] lần node vào danh sách

            temp = temp.next;
        }
    }
}

1. **`for (int i = 0; i < freq.length; i++)`**

   * Duyệt toàn bộ mảng tần suất `freq`.

2. **`if (freq[i] > 0)`**

   * `i` là chỉ số trong mảng `freq`.

     * Lặp đúng số lần `freq[i]`.

### 1️⃣ Dịch giá trị gốc sang chỉ số mảng

Mỗi giá trị gốc `val` → lưu vào `freq[val + min]`

```
 val   + min (=3)   → index trong freq
-------------------------------------
 -3    + 3 = 0      → freq[0]++
 -1    + 3 = 2      → freq[2]++
  0    + 3 = 3      → freq[3]++
  2    + 3 = 5      → freq[5]++
```

👉 Mảng freq sau khi đếm:

```
index:  0   1   2   3   4   5
freq : [1, 0, 1, 1, 0, 1]
```

---

### 2️⃣ Duyệt mảng freq để khôi phục giá trị

Công thức:

```java
val = i - min
```

```
 index   freq[i]   val = i - min (3)
------------------------------------
   0        1           0 - 3 = -3
   1        0           1 - 3 = -2   (nhưng freq=0 → bỏ qua)
   2        1           2 - 3 = -1
   3        1           3 - 3 = 0
   4        0           4 - 3 = 1   (bỏ qua)
   5        1           5 - 3 = 2
```

---

### 3️⃣ Kết quả cuối cùng

Ta tái tạo lại list:

```
-3 → -1 → 0 → 2
```

Đúng thứ tự ban đầu đã merge sorted! ✅

---

📌 **Tóm lại sơ đồ:**

```
Giá trị gốc (val) ──(+min)──▶ index freq
       ▲                             │
       └──────(i - min)──────────────┘
```

---

Bạn có muốn mình viết lại đoạn code **Java có thêm println debug** để khi chạy bạn thấy rõ mapping `val → index` và `index → val` không?
Ok mình tập trung giải thích đúng chỗ bạn chưa hiểu:

`val = i - min;` dùng để **khôi phục giá trị thật** từ chỉ số `i` trong mảng `freq`.

---

### Vì sao cần làm vậy?

Khi lưu giá trị vào mảng `freq`, ta đã **dịch đi** một đoạn `+min` để loại bỏ số âm.
👉 Ví dụ: nếu `min = 3` (do trong danh sách có số âm nhỏ nhất là -3), thì:

* Giá trị thật `-3` được lưu tại `freq[0]` (vì -3 + 3 = 0)
* Giá trị thật `-1` được lưu tại `freq[2]` (vì -1 + 3 = 2)
* Giá trị thật `0` được lưu tại `freq[3]` (vì 0 + 3 = 3)
* Giá trị thật `2` được lưu tại `freq[5]` (vì 2 + 3 = 5)

---

### Khi duyệt ngược lại

Lúc xuất dữ liệu, `i` chính là chỉ số trong mảng `freq`.
Nhưng đó là chỉ số **đã bị dịch**.
Muốn lấy lại giá trị ban đầu ⇒ phải **dịch ngược lại**.

👉 Công thức:

```
val = i - min
```

---

### Ví dụ minh họa

Giả sử `min = 3`.

| i (chỉ số mảng) | val = i - min | Ý nghĩa              |
| --------------- | ------------- | -------------------- |
| 0               | 0 - 3 = -3    | Khôi phục giá trị -3 |
| 2               | 2 - 3 = -1    | Khôi phục giá trị -1 |
| 3               | 3 - 3 = 0     | Khôi phục giá trị 0  |
| 5               | 5 - 3 = 2     | Khôi phục giá trị 2  |

---

👉 Vậy: `val = i - min` chính là bước **dịch ngược lại** để lấy số gốc (trước khi cộng `+min`).
