976. Largest Perimeter Triangle(28/09/2025)
class Solution {
    public int largestPerimeter(int[] nums) {
        int n = nums.length;

        //Just find two largest elements. No need to sort the whole array
        selectAndSwapMax(nums, n - 1);
        selectAndSwapMax(nums, n - 2);

        // Iterate backward from the end to the third element
        for (int i = n - 1; i >= 2; i--) {

            //Find third element inside the loop because of the inequality condition :
            // Place the third max element in nums[0..i-2] at position i-2
            selectAndSwapMax(nums, i - 2);

            // Check the triangle inequality on the triplet
            if (nums[i] < nums[i - 1] + nums[i - 2]) {
                return nums[i] + nums[i - 1] + nums[i - 2];
            }
        }

        // No valid triangle found
        return 0;
    }

    // Selects the maximum element from nums[0..idx] and swaps it with nums[idx]
    private void selectAndSwapMax(int[] nums, int idx) {
        int maxValue = nums[0];
        int maxIndex = 0;

        // Find the max element and its index in nums[0..idx]
        for (int i = 1; i <= idx; i++) {
            if (nums[i] > maxValue) {
                maxValue = nums[i];
                maxIndex = i;
            }
        }

        // Swap max element to the position idx
        int temp = nums[idx];
        nums[idx] = maxValue;
        nums[maxIndex] = temp;
    }
}

### 🎯 Mục tiêu

Tìm **chu vi lớn nhất** của một tam giác có thể tạo thành từ các cạnh trong mảng `nums`.
Điều kiện để 3 cạnh tạo thành tam giác là:

```
a + b > c
```

(với `c` là cạnh lớn nhất trong bộ ba).

---

### 🚀 Ý tưởng chính

* Không cần **sắp xếp cả mảng** (O(n log n)), chỉ cần **tìm dần các cạnh lớn nhất**.
* Mỗi lần lấy ra 3 cạnh lớn nhất còn lại, kiểm tra xem có tạo thành tam giác không.
* Nếu có → trả về ngay chu vi (vì chắc chắn đây là chu vi lớn nhất).

---

### 1. Mảng sau khi xử lý (hoặc sort) thì **các cạnh lớn nhất nằm ở cuối**

* Sau khi gọi `selectAndSwapMax`, ta đảm bảo **2 cạnh lớn nhất** nằm ở `nums[n-1]` và `nums[n-2]`.
* Như vậy, khi bắt đầu xét từ `i = n-1`, ta luôn **xem xét tam giác có cạnh lớn nhất hiện tại**.

---

### 2. Mục tiêu là tìm **chu vi lớn nhất**

* Chu vi tam giác phụ thuộc vào **3 cạnh lớn nhất có thể ghép được**.
* Nếu ta duyệt từ **lớn → nhỏ** (ngược), thì:

  * Bộ ba đầu tiên thỏa mãn bất đẳng thức tam giác chính là **chu vi lớn nhất**.
  * Gặp tam giác hợp lệ thì trả về ngay → không cần xét tiếp (tối ưu).

---

### 3. Nếu duyệt xuôi (từ nhỏ → lớn) thì sao?

* Ta sẽ phải kiểm tra **rất nhiều bộ ba không cần thiết**.
* Ví dụ: với mảng `[2,3,4,5,10]`:

  * Nếu duyệt xuôi, ta sẽ xét `(2,3,4)`, `(2,3,5)`, `(2,3,10)`… nhưng hầu hết sẽ không thỏa.
  * Trong khi duyệt ngược, ta chỉ cần kiểm tra `(10,5,4)` trước. Nếu hợp lệ thì dừng ngay → nhanh hơn.

### 🔎 Kết luận

👉 **Duyệt ngược để ưu tiên xét tam giác có cạnh lớn nhất trước**.

* Nếu hợp lệ → chắc chắn đó là **chu vi lớn nhất**.
* Nếu không → giảm dần cạnh lớn nhất rồi thử tiếp.

### 📌 Code

```java
private void selectAndSwapMax(int[] nums, int idx) {
    int maxValue = nums[0];
    int maxIndex = 0;

    // Find the max element and its index in nums[0..idx]
    for (int i = 1; i <= idx; i++) {
        if (nums[i] > maxValue) {
            maxValue = nums[i];
            maxIndex = i;
        }
    }

    // Swap max element to the position idx
    int temp = nums[idx];
    nums[idx] = maxValue;
    nums[maxIndex] = temp;
}
```

---

### 🔎 Giải thích từng bước

1. **Khởi tạo giá trị lớn nhất ban đầu:**

```java
int maxValue = nums[0];
int maxIndex = 0;
```

* Giả sử phần tử đầu tiên `nums[0]` là lớn nhất.
* Lưu vị trí (`maxIndex`) và giá trị (`maxValue`) tạm thời.

---

2. **Duyệt mảng từ `0..idx` để tìm số lớn nhất:**

```java
for (int i = 1; i <= idx; i++) {
    if (nums[i] > maxValue) {
        maxValue = nums[i];
        maxIndex = i;
    }
}
```

* Với mỗi phần tử, nếu thấy số lớn hơn `maxValue` thì cập nhật:

  * `maxValue` = giá trị mới.
  * `maxIndex` = vị trí mới.

👉 Sau vòng lặp, ta có được **giá trị lớn nhất trong đoạn `0..idx`**.

---

3. **Hoán đổi phần tử lớn nhất về cuối đoạn (vị trí `idx`):**

```java
int temp = nums[idx];
nums[idx] = maxValue;
nums[maxIndex] = temp;
```

* Lấy phần tử lớn nhất vừa tìm được và đưa nó về vị trí `idx`.
* Đảm bảo `nums[idx]` chính là **giá trị lớn nhất trong `nums[0..idx]`**.

---

### 📌 Ví dụ minh họa

Giả sử mảng:

```
nums = [3, 6, 2, 8, 4], idx = 4
```

* Tìm max trong `nums[0..4]` → max = 8 ở vị trí 3.
* Hoán đổi `nums[4]` với `nums[3]`.

Kết quả:

```
nums = [3, 6, 2, 4, 8]
```

👉 `nums[4]` bây giờ là lớn nhất.

➡️ Tóm lại: `selectAndSwapMax` giúp **chọn số lớn nhất trong đoạn 0..idx và đưa nó ra cuối đoạn**, giống như một bước trong **selection sort**.
