    public static int maxFreqSum(String s) {
        // Mảng đếm tần suất các chữ cái a-z
        int[] cnt = new int[26];
        for (char c : s.toCharArray()) {

Ok 👍 mình sẽ giải thích thật kỹ đoạn code này trong Java:

```java
int[] cnt = new int[26];
for (char c : s.toCharArray()) {
```

---

### 1. `int[] cnt = new int[26];`

* Tạo một mảng số nguyên `cnt` có 26 phần tử.
* Mỗi phần tử tương ứng với một chữ cái từ `'a'` → `'z'`.
* Ban đầu tất cả phần tử = 0.

Ví dụ:
`cnt[0]` → số lần xuất hiện của `'a'`
`cnt[1]` → số lần xuất hiện của `'b'`
...
`cnt[25]` → số lần xuất hiện của `'z'`

---

### 2. `s.toCharArray()`

* Biến chuỗi `s` thành một mảng ký tự (`char[]`).
* Ví dụ:
  `"leetcode".toCharArray()` → `['l','e','e','t','c','o','d','e']`

---

### 3. `for (char c : s.toCharArray())`

* Đây là vòng lặp **for-each**.
* Nó sẽ duyệt qua từng ký tự `c` trong mảng ký tự vừa tạo.

Ví dụ:

* Lần 1: `c = 'l'`
* Lần 2: `c = 'e'`
* Lần 3: `c = 'e'`
* ...

---

### 4. `cnt[c - 'a']++`

* Biểu thức `c - 'a'` tính chỉ số tương ứng của ký tự `c`.

  * `'a' - 'a' = 0` → chỉ số 0
  * `'b' - 'a' = 1` → chỉ số 1
  * `'c' - 'a' = 2` → chỉ số 2
  * ...
  * `'z' - 'a' = 25` → chỉ số 25

* `cnt[c - 'a']++` nghĩa là tăng bộ đếm cho ký tự đó lên 1.

Ví dụ với `"leetcode"`:

* `c = 'l'` → `'l' - 'a' = 11` → `cnt[11]++`
* `c = 'e'` → `'e' - 'a' = 4` → `cnt[4]++`
* ...

Kết quả cuối cùng:
`cnt[4] = 3` (chữ `'e'` xuất hiện 3 lần)
`cnt[11] = 1` (chữ `'l'`)
`cnt[14] = 1` (chữ `'o'`)
`cnt[19] = 1` (chữ `'t'`)
`cnt[2] = 1` (chữ `'c'`)
`cnt[3] = 1` (chữ `'d'`)

---

* Đoạn `for` này duyệt toàn bộ chuỗi `s`.
* Với mỗi ký tự, nó ánh xạ về chỉ số trong mảng `cnt` (0–25).
* Sau đó tăng bộ đếm ở vị trí đó lên 1.
* Kết quả: `cnt[i]` lưu **số lần xuất hiện** của ký tự `'a'+i`.

### 1. Ý tưởng

* Biến `i` là **số nguyên** từ `0` → `25`.
* `'a'` trong Java có giá trị **ASCII = 97**.
* Khi viết `i + 'a'`, ta lấy số nguyên `i` cộng với 97.
* Sau đó ép kiểu `(char)` để chuyển số nguyên đó về **ký tự chữ cái**.

---

### 2. Ví dụ minh họa

Giả sử đang duyệt `i` từ 0 → 25:

| i  | i + 'a' (giá trị số) | (char)(i + 'a') | Ký tự tương ứng |
| -- | -------------------- | --------------- | --------------- |
| 0  | 0 + 97 = 97          | (char)97        | `'a'`           |
| 1  | 1 + 97 = 98          | (char)98        | `'b'`           |
| 2  | 2 + 97 = 99          | (char)99        | `'c'`           |
| …  | …                    | …               | …               |
| 11 | 11 + 97 = 108        | (char)108       | `'l'`           |
| 25 | 25 + 97 = 122        | (char)122       | `'z'`           |

### 3. Ý nghĩa

Ví dụ:

---

### 📝 Tóm tắt 2 dòng code:

```java
for (char c : s.toCharArray()) {
    cnt[c - 'a']++;
}
```

1. `s.toCharArray()` → biến chuỗi thành mảng ký tự.
   Ví dụ `"abc"` → `['a','b','c']`.

2. `for (char c : ...)` → duyệt từng ký tự trong chuỗi.

3. `cnt[c - 'a']++` → đếm số lần xuất hiện của ký tự:

   * `'a'` → 0
   * `'b'` → 1
   * `'c'` → 2
   * ...
   * `'z'` → 25

---

### 💡 Cách nhớ nhanh:

* `"toCharArray"` = tách chuỗi → ký tự.
* `"c - 'a'"` = vị trí trong bảng chữ cái (0–25).
* `"cnt[ ]++"` = cộng thêm 1 lần xuất hiện.

---

👉 Một câu gói gọn:
**“Tách chuỗi → duyệt từng ký tự → biến ký tự thành số 0–25 → cộng vào mảng cnt để đếm tần suất.”**
