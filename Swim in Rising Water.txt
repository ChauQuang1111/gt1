class Solution {
  int len;
final static int[][] dirs = new int[][]{{1,0},{0,1},{-1,0},{0,-1}};

public int swimInWater(int[][] grid) {
    len = grid.length;
    int left = Math.max(grid[0][0], grid[len - 1][len - 1]), right = len * len - 1, mid, res = 0;
    while (left <= right) {
        mid = (left + right) / 2;
        boolean[] seen = new boolean[len * len];
        if (dfs(0, 0, grid, mid, seen)) {
            res = mid;
            right = mid - 1;
        } else {
            left = mid + 1;
        }
    }
    return res;
}
public boolean dfs(int xn, int yn, int[][] grid, int mid, boolean[] seen) {
    int idx = xn * len + yn;
    if (seen[idx]) return true;
    seen[idx] = true;
    for (int i = 0; i < 4; i++) {
        int newx = xn + dirs[i][0], newy = yn + dirs[i][1];
        if (newx >= 0 && newx < len && newy >= 0
                && newy < len && !seen[newx * len + newy] && grid[newx][newy] <= mid) {
            if (newx == len - 1 && newy == len - 1) {
                return true;
            }
            if (dfs(newx, newy, grid, mid, seen)) {
                return true;
            }
        }
    }
    return false;
}
}

#### ✅ Nếu `dfs(...)` trả về **true**:

* Nghĩa là **có thể đi từ (0,0) → (n-1,n-1)** khi nước cao `mid`.
* Khi đó:

  * `res = mid`: cập nhật kết quả (tạm thời là mức nước đủ).
  * `right = mid - 1`: thử **giảm mực nước xuống** để tìm giá trị nhỏ hơn vẫn đi được.

#### ❌ Nếu `dfs(...)` trả về **false**:

* Nghĩa là nước còn **chưa đủ cao để đi hết**.
* Khi đó:

  * `left = mid + 1`: **tăng mực nước lên**.

### 🧠 Ý tưởng tổng quát:

Hàm `dfs` dùng để **kiểm tra xem có thể đi từ (0,0) đến (n-1,n-1)** khi mức nước hiện tại là `mid` hay không.
Nếu tại mức nước `mid`, ta có thể đi qua các ô có giá trị ≤ `mid`, thì ta thử mức nước nhỏ hơn. Ngược lại, tăng mức nước lên.

---

### 💻 Code kèm chú thích:

```java
public boolean dfs(int xn, int yn, int[][] grid, int mid, boolean[] seen) {
    // Tính chỉ số 1D tương ứng của ô (xn, yn) trong mảng seen 1D
    int idx = xn * len + yn;

    // Nếu ô này đã được thăm, trả về true (tránh lặp vô hạn)
    if (seen[idx]) return true;

    // Đánh dấu ô hiện tại đã được thăm
    seen[idx] = true;

    // Duyệt 4 hướng: lên, xuống, trái, phải
    for (int i = 0; i < 4; i++) {
        int newx = xn + dirs[i][0], newy = yn + dirs[i][1];

        // Kiểm tra ô mới có nằm trong lưới và chưa thăm
        // đồng thời độ cao của ô đó ≤ mid (tức là có thể bơi qua)
        if (newx >= 0 && newx < len && newy >= 0
                && newy < len && !seen[newx * len + newy] && grid[newx][newy] <= mid) {

            // Nếu đã đến được đích (len-1, len-1) thì trả về true
            if (newx == len - 1 && newy == len - 1) {
                return true;
            }

            // Tiếp tục DFS sang ô mới
            if (dfs(newx, newy, grid, mid, seen)) {
                return true; // Nếu đường đi hợp lệ, trả về true ngay
            }
        }
    }

    // Nếu thử mọi hướng đều không đến được đích => false
    return false;
}
```

---

### 📘 Tóm tắt hoạt động:

* `mid` đại diện cho **mực nước hiện tại**.
* `dfs()` duyệt **tất cả các ô có thể bơi tới** (độ cao ≤ `mid`).
* Nếu có đường đến `(len-1, len-1)` → `true`.
* Nếu không tìm thấy đường → `false`.
* Kết hợp với **Binary Search** trong hàm `swimInWater` để tìm **mức nước nhỏ nhất cần thiết**.
