Delete Nodes From Linked List Present in Array
class Solution {
    public ListNode modifiedList(int[] nums, ListNode head) {
        int max = -1;
        for(int num : nums ){
            max = num > max ? num : max;
        }
        boolean[] freq = new boolean[max+1];

        for(int num : nums) freq[num] = true;

        ListNode temp = new ListNode();
        ListNode current = temp;

        while(head != null){
            if( head.val >= freq.length || freq[head.val] == false){
                current.next = head;
                current = current.next;
            }
            head = head.next;
        }

        current.next = null;
        return temp.next;
    }
}
Rất tốt 👏 — mình sẽ giải thích chi tiết đoạn code Java này nhé:

---

### 🧩 Mục đích:

Tìm **giá trị lớn nhất (`max`)** trong mảng `nums`.

---

### 💡 Giải thích từng dòng:

```java
int max = -1;
```

* Khởi tạo biến `max` bằng `-1`.
* Nghĩa là giả sử ban đầu giá trị lớn nhất là `-1`.
  (Nếu mảng toàn số dương thì điều này an toàn,
  còn nếu có số âm thì nên khởi tạo khác — mình sẽ nói thêm bên dưới).

---

```java
for (int num : nums) {
    max = num > max ? num : max;
}
```

Đây là **vòng lặp for-each**:

* Duyệt qua từng phần tử `num` trong mảng `nums`.
* Toán tử ba ngôi `?:` hoạt động như sau:

  ```java
  max = (num > max) ? num : max;
  ```

  → Nếu `num` lớn hơn `max`, thì gán `max = num`.
  → Ngược lại, giữ nguyên `max`.

---

### ✅ Kết quả:

Sau khi vòng lặp kết thúc, `max` chứa **giá trị lớn nhất trong mảng `nums`**.

---

### 📊 Ví dụ:

Giả sử:

```java
int[] nums = {3, 9, 5, 1};
```

| num | max trước | num > max? | max sau |
| --- | --------- | ---------- | ------- |
| 3   | -1        | ✅          | 3       |
| 9   | 3         | ✅          | 9       |
| 5   | 9         | ❌          | 9       |
| 1   | 9         | ❌          | 9       |

👉 Kết quả cuối cùng: `max = 9`

---

### ⚠️ Lưu ý:

Nếu mảng `nums` có thể chứa số âm, thì dòng đầu nên viết như sau:

```java
int max = Integer.MIN_VALUE;
```

hoặc

```java
int max = nums[0];
```

để đảm bảo đúng cho mọi trường hợp.

Rất hay 👏 — đoạn code này là **phần khởi tạo và xử lý danh sách liên kết (Linked List)** sau khi đã biết giá trị lớn nhất trong `nums`.
Giờ cùng mình giải thích chi tiết từng dòng nhé 👇

---

### 🧩 Toàn bộ đoạn code:

```java
boolean[] freq = new boolean[max + 1];

for (int num : nums) freq[num] = true;

ListNode temp = new ListNode();
ListNode current = temp;
```

---

### 🔍 Giải thích từng dòng

#### 1️⃣ `boolean[] freq = new boolean[max + 1];`

* Tạo một **mảng boolean** có kích thước `max + 1`.
* Dùng để **đánh dấu (mark)** xem số nào trong `nums` xuất hiện.

💡 Ví dụ:

```java
nums = [1, 3, 5];
max = 5;
```

→ `freq` sẽ là mảng có 6 phần tử (`[false, false, false, false, false, false]` ban đầu).

---

#### 2️⃣ `for (int num : nums) freq[num] = true;`

* Với mỗi phần tử `num` trong `nums`, gán `freq[num] = true`.
* Sau vòng lặp, `freq[i] == true` nghĩa là giá trị `i` **có trong nums**.

📊 Tiếp tục ví dụ trên:

```java
nums = [1, 3, 5];
```

→ Sau vòng lặp:
`freq = [false, true, false, true, false, true]`
(nghĩa là 1, 3, 5 có trong mảng)

---

#### 3️⃣ `ListNode temp = new ListNode();`

* Tạo một **node tạm** (dummy node) cho danh sách liên kết mới.
* `temp` đóng vai trò **gốc giả** để việc nối node sau này dễ dàng hơn.

📘 Dummy node là kỹ thuật phổ biến trong Linked List:

> giúp tránh phải xử lý riêng trường hợp danh sách rỗng hoặc node đầu tiên.

---

#### 4️⃣ `ListNode current = temp;`

* Tạo biến `current` để **duyệt và xây dựng danh sách mới**.
* Ban đầu, `current` trỏ cùng chỗ với `temp`.
* Khi thêm node mới, ta sẽ gán `current.next = newNode` rồi cập nhật `current = current.next`.

---

### 🧠 Tổng kết ý nghĩa:

| Dòng                                     | Chức năng                          |
| ---------------------------------------- | ---------------------------------- |
| `boolean[] freq = new boolean[max+1];`   | Tạo bảng đánh dấu số nào cần xóa   |
| `for (int num : nums) freq[num] = true;` | Ghi lại các giá trị bị “cấm”       |
| `ListNode temp = new ListNode();`        | Tạo node gốc tạm cho danh sách mới |
| `ListNode current = temp;`               | Dùng để nối các node giữ lại       |

---

👉 Sau đoạn này, code thường sẽ tiếp tục như sau:

```java
while (head != null) {
    if (!freq[head.val]) {
        current.next = new ListNode(head.val);
        current = current.next;
    }
    head = head.next;
}
return temp.next;
```

Đoạn trên sẽ **tạo danh sách mới** chỉ gồm các node mà giá trị **không nằm trong `nums`**.

Tuyệt vời 👏 — đoạn bạn gửi bây giờ là **phần hoàn chỉnh của hàm xử lý danh sách liên kết** trong Java.
Mình sẽ giúp bạn hiểu rõ **toàn bộ đoạn `while` này hoạt động thế nào**, và **vì sao nó chạy đúng** nhé 👇

---

### 🧩 Code:

```java
while (head != null) {
    if (head.val >= freq.length || freq[head.val] == false) {
        current.next = head;
        current = current.next;
    }
    head = head.next;
}

current.next = null;
return temp.next;
```

---

### 🧠 Mục tiêu:

Tạo **một danh sách mới**, chỉ chứa **những node không nằm trong `nums`**
(dựa trên mảng `freq` bạn đã tạo ở phần trước).

---

### 🔍 Giải thích chi tiết từng phần:

#### 1️⃣ `while (head != null)`

* Duyệt toàn bộ danh sách liên kết gốc, bắt đầu từ `head`.

---

#### 2️⃣ `if (head.val >= freq.length || freq[head.val] == false)`

Điều kiện giữ lại node này:

* `head.val >= freq.length`:
  Giá trị node **vượt ngoài phạm vi** của mảng `freq`.
  (ví dụ: `head.val = 100`, mà `max = 50` → không nằm trong nums → nên giữ lại)

* `freq[head.val] == false`:
  Giá trị này **không xuất hiện trong nums** → giữ lại.

➡️ Nói cách khác:
**chỉ thêm node vào danh sách mới nếu nó KHÔNG cần bị xóa.**

---

#### 3️⃣ `current.next = head;`

* Nối node hiện tại (`head`) vào danh sách mới (được xây qua `current`).

---

#### 4️⃣ `current = current.next;`

* Di chuyển con trỏ `current` sang node mới vừa thêm — để sẵn sàng nối node tiếp theo.

---

#### 5️⃣ `head = head.next;`

* Di chuyển `head` sang node kế tiếp trong danh sách gốc.

---

#### 6️⃣ `current.next = null;`

* Sau khi kết thúc vòng lặp, có thể `current.next` vẫn trỏ tới một node cũ (bị bỏ qua).
* Gán `current.next = null` để **cắt đuôi danh sách** cho chắc chắn.

---

#### 7️⃣ `return temp.next;`

* `temp` là **dummy node (node tạm)** mà ta tạo ở đầu.
* `temp.next` chính là **node đầu tiên thật sự của danh sách mới** (sau khi loại bỏ các node cần xóa).

---

### ✅ Tóm tắt toàn logic của hàm

| Bước               | Mục đích                          | Giải thích                                  |
| ------------------ | --------------------------------- | ------------------------------------------- |
| Tạo `freq`         | Đánh dấu các giá trị trong `nums` | `freq[val] = true` nghĩa là giá trị cần xóa |
| Duyệt danh sách    | Kiểm tra từng node                | Nếu node không nằm trong `nums` thì giữ lại |
| Dựng danh sách mới | Dùng con trỏ `current`            | Liên kết các node hợp lệ                    |
| Cắt đuôi           | `current.next = null`             | Tránh dính node cũ                          |
| Trả kết quả        | `return temp.next`                | Head của danh sách mới                      |

---

### 📊 Ví dụ minh họa

Giả sử:

```java
nums = [2, 5];
head = 1 → 2 → 3 → 4 → 5 → 6
```

**Tạo freq:**
`freq = [false, false, true, false, false, true, false]`

| 2    | true       | ❌        | 1             |
| 3    | false      | ✅        | 1 → 3         |

| 5    | true       | ❌        | 1 → 3 → 4     |
| 6    | false      | ✅        | 1 → 3 → 4 → 6 |

**Kết quả cuối:**
`1 → 3 → 4 → 6`
