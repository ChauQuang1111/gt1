class Router {
    Deque<int[]>que;
    HashMap<Integer,List<int[]>>map;
    int size;
    public Router(int memoryLimit) {
        que=new LinkedList<>();
        map=new HashMap<>();
        this.size=memoryLimit;
    }
    
    public boolean addPacket(int source, int destination, int timestamp) {
        
        if(!map.containsKey(destination)){
            map.put(destination,new ArrayList<>());
        }
        List<int[]>list=map.get(destination);
        int left=small(list,timestamp);
        
        if(list.size()!=0){
           
            for(int i=left;i<list.size() && list.get(i)[1]==timestamp;i++){
                if(list.get(i)[0]==source)return false;
            }
        }
        map.get(destination).add(new int[]{source,timestamp});
        que.addLast(new int[]{source,destination,timestamp});
        if(que.size()>size){
            forwardPacket();
        }
        
        return true;
        
    }
    
    public int[] forwardPacket() {
        if(que.size()==0)return new int[0];
        int[]arr=que.pollFirst();
        // System.out.println(Arrays.toString(arr));
        map.get(arr[1]).remove(0);
        return arr;
    }
    
    public int getCount(int destination, int startTime, int endTime) {
        if(!map.containsKey(destination)){
            return 0;
        }
        List<int[]>list=map.get(destination);
        int left=small(list,startTime);
        int right=big(list,endTime);
        if(left>right)return 0;
        return right-left+1;
    }
    public int small(List<int[]>list,int start){
        int left=0;
        int right=list.size()-1;
        while(left<=right){
            int mid=left+(right-left)/2;
            if(list.get(mid)[1]>=start){
                right=mid-1;
            }
            else{
                left=mid+1;
            }
        }
        return left;
    }
    public int big(List<int[]>list,int end){
        int left=0;
        int right=list.size()-1;
        while(left<=right){
            int mid=left+(right-left)/2;
            if(list.get(mid)[1]>end){
                right=mid-1;
            }
            else{
                left=mid+1;
            }
        }
        return right;
    }
}

🔎 Ý nghĩa:

* `list` chứa các gói tin theo **destination**, dạng `{source, timestamp}`.
* Khi thêm gói tin mới `(source, destination, timestamp)`, ta dùng `small(list, timestamp)` để tìm **vị trí đầu tiên có timestamp >= timestamp**.
* Sau đó duyệt các phần tử tiếp theo có cùng `timestamp`.
* Nếu thấy `source` đã tồn tại trong cùng `timestamp` → gói tin trùng → **không thêm** (trả về `false`).
* Nếu không trùng thì thoải mái thêm vào `list` và `que`.

👉 Nói ngắn gọn: đoạn này đảm bảo **một destination tại một timestamp chỉ có duy nhất 1 gói tin từ cùng source**.

Câu hỏi hay 👌

👉 Lý do **bắt đầu từ bên trái (left)** là vì `left = small(list, timestamp)` đã được viết như một **binary search** để tìm **chỉ số đầu tiên trong list có `timestamp >=` giá trị mình cần**.

Nghĩa là:

* Các gói tin trong `list` **theo destination** luôn được thêm theo **thứ tự thời gian tăng dần** (vì khi addPacket, ta luôn append cuối list).
* Hàm `small(list, timestamp)` trả về vị trí **đầu tiên có timestamp >= timestamp cần tìm**.

Ví dụ:

```
list = [ (A,1), (B,3), (C,3), (D,5) ]
timestamp = 3
```

→ `small(list,3)` sẽ trả về index = 1 (ứng với `(B,3)`).

Vậy nên:

```java

```

sẽ duyệt **tất cả gói tin có timestamp == 3**.
Nếu có source trùng thì return false ngay.

⚡ Nếu bạn duyệt từ đầu list (`i=0`) thì sẽ phải check tất cả → **thừa thãi**.
⚡ Nếu bạn duyệt từ giữa mà không dựa trên binary search, bạn có thể bỏ sót các gói tin cùng timestamp.

👉 Do đó, bắt đầu từ `left` là **tối ưu nhất**: chỉ duyệt đúng đoạn có timestamp cần kiểm tra.

Ok mình giải thích chi tiết đoạn `forwardPacket()` này nhé 👇

```java
public int[] forwardPacket() {
    // Nếu hàng đợi trống thì trả về mảng rỗng
    if (que.size() == 0) return new int[0];

    // Lấy gói tin đầu tiên trong queue (FIFO)
    int[] arr = que.pollFirst();  

    // Xóa gói tin tương ứng trong map (theo destination arr[1])
    map.get(arr[1]).remove(0);

    // Trả về gói tin vừa forward
    return arr;
}
```

---

🔎 Từng bước:

1. **Kiểm tra queue trống**

   ```java
   if (que.size() == 0) return new int[0];
   ```

   * Nếu không còn gói tin nào → return mảng rỗng `{}`.

2. **Lấy gói tin theo FIFO**

   ```java
   int[] arr = que.pollFirst();
   ```

   * `que` là `Deque<int[]>`, hoạt động như một queue FIFO.
   * `pollFirst()` lấy phần tử đầu tiên và đồng thời xóa nó khỏi queue.
   * Gói tin `arr` có dạng `{source, destination, timestamp}`.

3. **Xóa gói tin trong map**

   ```java
   map.get(arr[1]).remove(0);
   ```

   * `arr[1]` là **destination**.
   * Trong `map`, key = destination, value = danh sách gói tin `{source, timestamp}` theo destination.
   * Vì gói tin trong queue luôn khớp với phần tử **đầu tiên** trong list của `map.get(destination)` (do FIFO đồng bộ với insert vào list), nên ta chỉ cần `remove(0)`.

4. **Trả về gói tin vừa forward**

   ```java
   return arr;
   ```

   * Giúp bên ngoài biết gói tin nào vừa được forward.

---

Giả sử:

* Lấy `{1,10,5}` khỏi `que`.

Bạn có muốn mình viết lại `forwardPacket()` theo cách an toàn hơn (ví dụ check null, tránh lỗi `remove(0)` khi list rỗng) không?

```java
public int getCount(int destination, int startTime, int endTime) {
    if (!map.containsKey(destination)) {
        return 0;
    }
    List<int[]> list = map.get(destination);
    int left = small(list, startTime);
    int right = big(list, endTime);
    if (left > right) return 0;
    return right - left + 1;
}
```

---

### 📌 Mục đích của hàm

👉 `getCount(destination, startTime, endTime)` dùng để **đếm số gói tin gửi tới một `destination` cụ thể trong khoảng thời gian `[startTime, endTime]`**.

---

### 📌 Từng bước hoạt động

1. **Kiểm tra destination có tồn tại trong map không**

   ```java
   if (!map.containsKey(destination)) {
       return 0;
   }
   ```

   * Nếu chưa có gói tin nào đến `destination` này → trả về 0 ngay.

2. **Lấy danh sách các gói tin cho destination**

   ```java
   List<int[]> list = map.get(destination);
   ```

   * `list` chứa các gói tin `{source, timestamp}` được sắp xếp tăng dần theo `timestamp`.

3. **Tìm vị trí biên trái và biên phải trong list**

   ```java
   int left = small(list, startTime);
   int right = big(list, endTime);
   ```

   * `small(list, startTime)` → trả về chỉ số **đầu tiên có timestamp ≥ startTime**.
   * `big(list, endTime)` → trả về chỉ số **cuối cùng có timestamp ≤ endTime**.

4. **Nếu không tìm thấy gói tin hợp lệ**

   ```java
   if (left > right) return 0;
   ```

   * Tức là không có gói tin nào trong khoảng `[startTime, endTime]`.

5. **Đếm số lượng gói tin hợp lệ**

   ```java
   return right - left + 1;
   ```

   * Số gói tin = chỉ số phải - chỉ số trái + 1.

---

Giả sử:


Gọi:


* `small(list, 10)` → index = 1 (timestamp 10).
* `big(list, 20)` → index = 3 (timestamp 20).
* Kết quả = `3 - 1 + 1 = 3`.

👉 Có **3 gói tin** đến `destination=100` trong khoảng `[10,20]`.

### 📌 Code bạn đưa

```java
public int small(List<int[]> list, int start) {
    int left = 0;
    int right = list.size() - 1;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (list.get(mid)[1] >= start) {
            right = mid - 1;
        } else {
            left = mid + 1;
        }
    }
    return left;
}
```

---

### 📌 Mục đích

`small(list, start)` tìm **chỉ số đầu tiên (index nhỏ nhất) trong list có `timestamp >= start`**.

---

### 📌 Giải thích từng bước

1. **Khởi tạo**

   ```java
   int left = 0;
   int right = list.size() - 1;
   ```

   * `left` trỏ về đầu list.
   * `right` trỏ về cuối list.
   * Vì list đã **sắp xếp tăng dần theo timestamp**, ta có thể dùng binary search.

2. **Vòng lặp binary search**

   ```java
   while (left <= right) {
       int mid = left + (right - left) / 2;
       ...
   }
   ```

   * Chia đôi list để kiểm tra.

3. **Nếu timestamp tại mid >= start**

   ```java
   if (list.get(mid)[1] >= start) {
       right = mid - 1;
   }
   ```

   * Nghĩa là `mid` có thể là một ứng viên (thoả điều kiện `>= start`).
   * Nhưng ta chưa chắc nó có phải là **chỉ số đầu tiên**.
   * Do đó ta **thu hẹp sang bên trái** để tìm chỉ số nhỏ hơn vẫn thoả điều kiện.

4. **Nếu timestamp tại mid < start**

   ```java
   else {
       left = mid + 1;
   }
   ```

   * Nghĩa là `mid` chưa đủ lớn (nhỏ hơn start).
   * Ta phải dịch sang **bên phải** để tìm timestamp lớn hơn.

5. **Kết quả**

   ```java
   return left;
   ```

   * Sau khi vòng lặp kết thúc, `left` chính là vị trí đầu tiên thoả `timestamp >= start`.
   * Nếu không có phần tử nào thoả → `left == list.size()`.

---

### 📌 Ví dụ minh hoạ

Giả sử list:

```
index: 0   1   2   3
value: 2   5   8   12   (timestamp)
```

Gọi `small(list, 6)`:

* B1: left=0, right=3 → mid=1 → value=5 < 6 → left=2
* B2: left=2, right=3 → mid=2 → value=8 >= 6 → right=1
* Vòng lặp dừng (left=2, right=1).

👉 Trả về `2` (tức là vị trí đầu tiên có timestamp ≥ 6).

---

### 1. `list.get(mid)[1]` nghĩa là gì?

* `list` lưu các gói tin dạng `{source, timestamp}`.
* `list.get(mid)` → lấy gói tin ở vị trí `mid`.
* `list.get(mid)[1]` → lấy **timestamp** của gói tin đó.

Ví dụ:

```

list.get(1)[1] = 10   // timestamp của gói tin số 2
```

### 2. So sánh với `start`

* `start` là thời gian bắt đầu cần tìm.
* `if (list.get(mid)[1] >= start)` kiểm tra xem timestamp ở giữa có **lớn hơn hoặc bằng thời điểm start** hay không.

---

### 3. Ý nghĩa trong thuật toán

* Nếu `list[mid].timestamp >= start`
  👉 Tức là phần tử ở giữa **đủ điều kiện** (>= start).
  Nhưng chưa chắc nó đã là **phần tử đầu tiên** thoả điều kiện.
  → Ta thu hẹp tìm kiếm sang **bên trái** để xem có phần tử nào nhỏ hơn nhưng vẫn >= start.

* Ngược lại, nếu `list[mid].timestamp < start`
  👉 Phần tử này quá nhỏ, chắc chắn không dùng được.
  → Ta phải dịch sang **bên phải** để tìm phần tử lớn hơn.

### 4. Ví dụ minh họa

```

```

* mid = 1 → timestamp = 5 → 5 >= 6 ? ❌ → dịch sang phải.
* mid = 2 → timestamp = 8 → 8 >= 6 ? ✅ → dịch sang trái để tìm nhỏ hơn nhưng vẫn ≥ 6.

Kết quả: chỉ số = 2 (timestamp = 8).

Bạn có muốn mình vẽ **sơ đồ mũi tên binary search** để thấy rõ cách left/right di chuyển khi gặp điều kiện này không?
À mình hiểu chỗ bạn thắc mắc rồi 👍

Trong hàm `small(List<int[]> list, int start)` thì mục tiêu là **tìm vị trí gói tin đầu tiên có `timestamp >= start`**.

👉 Giả sử `list` lưu các gói tin theo `timestamp` tăng dần:

| index | packet(timestamp) |
| ----- | ----------------- |
| 0     | 1                 |
| 1     | 2                 |
| 2     | 5                 |
| 3     | 7                 |
| 4     | 9                 |

Bây giờ gọi `small(list, start=2)`

### Cách hoạt động:

* Ta muốn **tìm index nhỏ nhất mà timestamp >= 2**
* `list[0][1] = 1 < 2` → không hợp, phải tìm bên phải
* `list[1][1] = 2 >= 2` → hợp lệ, nhưng **có thể còn phần tử nhỏ hơn vẫn hợp lệ** → tiếp tục dịch `right` về trái
* Kết quả cuối cùng = index 1

✅ Vậy khi bạn "tìm start=2" thì kết quả lấy **gói tin số 2** (timestamp=2), chứ không lấy số 1.

Nếu bạn thử `small(list, start=3)`

* Index trả về sẽ là `2` (packet có timestamp=5), vì `1` và `2` đều nhỏ hơn 3.

---

👉 Tóm lại:

* Nếu `list[mid][1] >= start` thì có khả năng đây là **ứng viên đúng**, nhưng phải kiểm tra tiếp xem còn gói tin nào bên trái (index nhỏ hơn) mà vẫn thoả mãn không.
* Do đó mới có dòng `right = mid - 1`.

Bạn có muốn mình làm thêm **ví dụ với start=2** (để thấy nó lấy gói tin số 2) không?
Rồi 👍 mình sẽ giải thích thật chi tiết cho bạn về hàm

```java
public int big(List<int[]> list, int end) {
    int left = 0;
    int right = list.size() - 1;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (list.get(mid)[1] > end) {
            right = mid - 1;
        } else {
            left = mid + 1;
        }
    }
    return right;
}
```

---

## 🎯 Mục đích của hàm

Hàm `big` dùng để tìm **chỉ số (index) của gói tin cuối cùng có `timestamp <= end`**.
Nói cách khác:

* `small` → tìm phần tử đầu tiên `>= start`.
* `big` → tìm phần tử cuối cùng `<= end`.

Giả sử ta có danh sách timestamp đã **tăng dần**:

```
index:   0   1   2   3   4
value:   1   2   5   7   9
```

## 📌 Tóm tắt logic

* Nếu `list[mid] > end` → phải đi về bên trái (loại bỏ phần tử này và các phần tử bên phải).
* Nếu `list[mid] <= end` → phần tử này hợp lệ, nhưng có thể còn phần tử lớn hơn vẫn hợp lệ, nên phải đi sang phải (`left = mid+1`).
* Sau khi kết thúc, `right` sẽ nằm ở **index cuối cùng ≤ end**.

👉 Đây là cặp đôi “binary search” thường dùng:

* `small` → tìm “lower bound” (first index ≥ start).
* `big` → tìm “upper bound” (last index ≤ end).

```java
public class TestBinarySearch {
    public static int small(List<int[]> list, int start) {
        int left = 0;
        int right = list.size() - 1;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (list.get(mid)[1] >= start) {
                right = mid - 1;
            } else {
                left = mid + 1;
            }
        }
        return left;
    }

    public static int big(List<int[]> list, int end) {
        int left = 0;
        int right = list.size() - 1;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (list.get(mid)[1] > end) {
                right = mid - 1;
            } else {
                left = mid + 1;
            }
        }
        return right;
    }

    public static void main(String[] args) {
        // List timestamp [1, 2, 5, 7, 9]
        List<int[]> list = new ArrayList<>();
        list.add(new int[]{0, 1});
        list.add(new int[]{0, 2});
        list.add(new int[]{0, 5});
        list.add(new int[]{0, 7});
        list.add(new int[]{0, 9});

        // Test small
        System.out.println("small(list, 6) = " + small(list, 6)); // index 3 → timestamp=7
        System.out.println("small(list, 5) = " + small(list, 5)); // index 2 → timestamp=5
        System.out.println("small(list, 10) = " + small(list, 10)); // index 5 (ngoài list)
```

## 🎯 Ý nghĩa

`getCount` cần đếm số gói tin của một `destination` trong **khoảng thời gian `[startTime, endTime]`**.
Để làm nhanh, ta dùng **binary search** (hàm `small` và `big`), thay vì duyệt cả list.

---

## 🔗 Cách dùng `small` + `big` trong `getCount`

```java
int left = small(list, startTime);   // chỉ số gói tin đầu tiên có timestamp >= startTime
int right = big(list, endTime);      // chỉ số gói tin cuối cùng có timestamp <= endTime
if (left > right) return 0;          // nếu không có gói tin hợp lệ
return right - left + 1;             // số gói tin trong đoạn
```

---

## 📌 Ví dụ minh hoạ

Giả sử gói tin của `destination=1` có timestamp:

```
timestamps = [1, 2, 5, 7, 9]
```

### Case 1: `getCount(1, 2, 7)`

* `small(list, 2)` → index 1 (timestamp=2).
* `big(list, 7)` → index 3 (timestamp=7).
* `count = 3 - 1 + 1 = 3`.
  👉 Có 3 gói tin trong khoảng `[2,7]` → {2, 5, 7}.

---

### Case 2: `getCount(1, 6, 8)`

* `small(list, 6)` → index 3 (timestamp=7).
* `big(list, 8)` → index 3 (timestamp=7).
* `count = 3 - 3 + 1 = 1`.
  👉 Có 1 gói tin trong khoảng `[6,8]` → {7}.

---

### Case 3: `getCount(1, 10, 20)`

* `small(list, 10)` → index 5 (ngoài list).
* `big(list, 20)` → index 4 (timestamp=9).
* Vì `left=5 > right=4` → return 0.
  👉 Không có gói tin nào trong khoảng `[10,20]`.
