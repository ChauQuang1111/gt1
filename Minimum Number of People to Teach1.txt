LeetCode 1733 – Minimum Number of People to Teach
class Solution {
    public int minimumTeachings(int n, int[][] L, int[][] F) {
        BitSet[] bit = new BitSet[L.length];
        Arrays.setAll(bit, o -> new BitSet(n + 1));
        for (int i = 0; i < L.length; i++){
            for (int l : L[i]){
                bit[i].set(l);
            }
        }
        Set<Integer> teach = new HashSet<>();
        for (int[] f : F){
            BitSet t = (BitSet)bit[f[0] - 1].clone();
            t.and(bit[f[1] - 1]);
            if (t.isEmpty()){
                teach.add(f[0] - 1);
                teach.add(f[1] - 1);
            }
        }
        int[] count = new int[n + 1];
        for (int person : teach){
            for (int l : L[person]){
                count[l]++;
            }
        }

        return teach.size() - Arrays.stream(count).max().getAsInt();
    }
}

### `BitSet` trong Java là gì?

* `BitSet` là một **cấu trúc dữ liệu** trong Java, dùng để lưu trữ các **bit** (0 hoặc 1).
* Nó giống như một **mảng Boolean** nhưng được nén lại để tiết kiệm bộ nhớ và hỗ trợ nhiều toán tử bit rất nhanh.

---

### 📌 Ví dụ trực quan

```java
BitSet b = new BitSet(6);
b.set(1);
b.set(4);
System.out.println(b); 
```

👉 Output:

```
{1, 4}
```

* Có nghĩa là `BitSet` này có **bit thứ 1** và **bit thứ 4** được bật (`true`), còn lại là `false`.
* Nếu coi như một mảng Boolean `[0, 1, 0, 0, 1, 0]` thì `BitSet` lưu ngắn gọn thành `{1, 4}`.

---

### 📌 Các thao tác hay dùng

* `set(i)` → bật bit thứ `i` (tức là đánh dấu phần tử `i` có tồn tại).
* `get(i)` → kiểm tra bit thứ `i` có được bật không.
* `clear(i)` → tắt bit thứ `i`.
* `and(other)` → giao 2 BitSet.
* `or(other)` → hợp 2 BitSet.
* `isEmpty()` → kiểm tra BitSet có rỗng không.

---

### 📌 Liên hệ với bài toán của bạn

Trong bài:

* Mỗi người biết một số ngôn ngữ.
* Thay vì lưu `List<Integer>`, ta dùng `BitSet` để đánh dấu.

  * Ví dụ: Người 0 biết `{2}`, thì `bit[0]` = `{2}`.
* Khi kiểm tra 2 người có giao tiếp được không:

  * Ta lấy `bit[ngườiA] AND bit[ngườiB]`.
  * Nếu kết quả rỗng → không có ngôn ngữ chung → không nói chuyện được.
  * Nếu có phần tử → họ có thể giao tiếp.

### 1. `Arrays.setAll(bit, o -> new BitSet(n + 1));` nghĩa là gì?

### 2. Vì sao `n + 1`?

* `n` = tổng số ngôn ngữ (theo đề).
* Các ngôn ngữ được đánh số từ **1 đến n** (1-based).
* Nhưng `BitSet` trong Java là **0-based index**.

Ví dụ:

* Nếu có 3 ngôn ngữ (1,2,3).
* Khi dùng `BitSet`:

  * Muốn bật ngôn ngữ 1 → `set(1)`
  * Muốn bật ngôn ngữ 3 → `set(3)`
* Như vậy, ta cần một `BitSet` có thể chứa được index **3**.
* Mà `BitSet(size)` có thể đánh dấu tới **size-1**, nên phải khai báo `n+1`.

👉 Tóm gọn:

* `+1` để **khớp với đánh số 1-based** của ngôn ngữ trong đề.
* Tránh lỗi khi truy cập ngôn ngữ số `n`.

```java
    t.and(bit[f[1] - 1]);
    System.out.println("Kiểm tra bạn: " + f[0] + " - " + f[1] + " → " + t);
}
```

* Với `[1,2]`:

  * `bit[f[0] - 1] = bit[0] = {1}`
  * `bit[f[1] - 1] = bit[1] = {2}`
  * Giao = rỗng (`{}`) → Người 1 và Người 2 **không nói chuyện được**.

* Với `[2,3]`:

  * `bit[1] = {2}`, `bit[2] = {3}`
  * Giao = rỗng (`{}`) → Người 2 và Người 3 **không nói chuyện được**.

✅ Đúng theo dữ liệu đề.

---

### 2️⃣ Trường hợp **không trừ 1**

```java
BitSet t = (BitSet) bit[f[0]].clone();
t.and(bit[f[1]]);
```

* Với `[1,2]`:

  * `bit[f[0]] = bit[1] = {2}` (đáng lẽ là Người 1, nhưng lấy nhầm sang Người 2)
  * `bit[f[1]] = bit[2] = {3}` (đáng lẽ là Người 2, nhưng lấy nhầm sang Người 3)
  * Giao = `{}` → thực chất đang kiểm tra Người 2 và 3 chứ **không phải 1 và 2** ❌

* Với `[2,3]`:

  * `bit[f[0]] = bit[2] = {3}`
  * `bit[f[1]] = bit[3]` → ❌ LỖI **ArrayIndexOutOfBoundsException** vì `bit[3]` không tồn tại.

---

### ✅ Kết luận

* Input `F` = 1-based (người đầu tiên là số 1).
* Mảng `bit[]` = 0-based (người đầu tiên là index 0).
* Do đó phải **trừ 1** để khớp index:

  * Người 1 → `bit[0]`
  * Người 2 → `bit[1]`
  * Người 3 → `bit[2]`

---

👉 Nếu không `-1`:

* sẽ **lấy nhầm người** khi kiểm tra,
* hoặc thậm chí **bị lỗi truy cập mảng**.

### Giải thích từng bước

1. **Cặp (1, 3):**

   * `f[0] = 1`, `f[1] = 3`.

   * `bit[f[1]-1] = bit[2] = {3}`

     → Không có ngôn ngữ chung → thêm `{0, 2}` vào `teach`.

2. **Cặp (2, 3):**

   * `f[0] = 2`, `f[1] = 3`.
   * `bit[f[0]-1] = bit[1] = {2}`
   * `bit[f[1]-1] = bit[2] = {3}`
   * Giao nhau: `{2} ∩ {3} = ∅`
     → Không có ngôn ngữ chung → thêm `{1, 2}` vào `teach`.
     (1 = người 2, 2 = người 3).

---

3. **Cặp (2, 4):**

   * `f[0] = 2`, `f[1] = 4`.
   * `bit[f[0]-1] = bit[1] = {2}`
   * `bit[f[1]-1] = bit[3] = {2,3}`
   * Giao nhau: `{2} ∩ {2,3} = {2}`
     → Có ngôn ngữ chung → bỏ qua.

`teach = {0, 1, 2}` → nghĩa là **người 1, 2, 3 (theo chỉ số 0-based)** cần được dạy thêm ngôn ngữ.

👉 Lý do phải `-1`:

* Vì dữ liệu input (f\[0], f\[1]) là **1-based** (người số 1 → index = 0).
* Trong Java, `bit` là mảng 0-based.
* Nếu không trừ 1 thì sẽ bị **lệch index** và lỗi `ArrayIndexOutOfBounds`.

### Code gốc:

```java
int[] count = new int[n + 1];

    }
}

```

### 📝 Giải thích từng dòng

#### 1. `int[] count = new int[n + 1];`

* Tạo một mảng `count` để **đếm số người trong `teach` biết từng ngôn ngữ**.
* Kích thước `n + 1` vì ngôn ngữ được đánh số từ `1 → n` (không dùng index 0).

Ví dụ:
Nếu có `n = 3` ngôn ngữ thì `count` có 4 ô:

```
index: 0   1   2   3
count: 0   0   0   0
```

---

#### 2.

```java
for (int person : teach){
    for (int l : L[person]){
        count[l]++;
    }
}
```

* Duyệt qua tất cả những người trong `teach` (những người cần học thêm).
* Với mỗi người, duyệt qua các ngôn ngữ mà họ **đã biết**.
* Với mỗi ngôn ngữ `l`, tăng `count[l]` thêm 1.

👉 Ý nghĩa:
`count[l]` = số người trong `teach` \*\*đã biết ngôn ngữ l\`.

---

#### 3.

```java
return teach.size() - Arrays.stream(count).max().getAsInt();
```

* `teach.size()` = tổng số người cần học.
* `Arrays.stream(count).max().getAsInt()` = tìm số lớn nhất trong `count` → tức là **ngôn ngữ phổ biến nhất trong tập `teach`**.

👉 Vì nếu mình chọn dạy thêm **ngôn ngữ này**, thì những người đã biết nó **không cần học lại**.

* Công thức:

```
Người cần dạy = Tổng số người trong teach - Số người đã biết ngôn ngữ phổ biến nhất
```

## 🔑 Pseudo-code

```

       For mỗi ngôn ngữ l trong L[p]:
            count[l]++
5. best = max(count)
6. return teach.size() - best
```

* Tìm tất cả người cần dạy (`teach`).
* Chọn ngôn ngữ phổ biến nhất trong nhóm đó.
